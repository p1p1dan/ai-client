二、为什么只有工具的改动？以及三种补法

这是当初的设计：面板记的是「这个对话的文件工具做了什么」，从对话历史里重建，每次 edit/write 一条，所以能说清是哪个对话、哪一步改的。Git 工作区说不出改动来自哪个对话，命令行（bash）和外部编辑器的改动当时就明确留到以后做，一直没做。底部那行「命令行和外部编辑不计入」就是这个意思。下面三种做法都只是把 Git 里已有的数据拿来显示，不需要新的记录机制：

1 维持现状，底部点明还有别的改动最小改动。列表照旧只有工具改的，末尾一行「工作区另有 2 个未提交的文件 · 在 Git 中查看」。
