谁来做全部交给随包的 CLI（claude plugin … --json），配置目录就是 Claude 对话的用户层 ~/.pilab/<配置名>/claude。装、关、卸、加市场的结果和在 Claude Code 里用 /plugin 一样，PiLab 不自己写 settings.json，也不复刻 CLI 的规则。2026-10-29 本机用随包 CLI 2.1.300 跑通了全流程：加官方市场 16 秒（git 克隆），列出 315 个插件，装 code-review 10 秒。
生效时机改动写进用户层后，新开的 Claude 对话直接生效；已经开着的对话下次启动时生效（CLI 的 /reload-plugins 只适合终端，菜单里本来就不列）。斜杠菜单的清单按文件夹缓存，改完要清掉缓存，否则首页菜单里看不到新插件的命令。
「里面有什么」每行标出插件带的技能、命令、子代理，以及钩子与MCP 服务——后两种会在本机运行程序，用黄色标出，和 Pi 插件的「写入文件」一样不会被忽略。数字是装好后读插件目录得到的；浏览列表里还不知道，只显示说明和安装量（CLI 的列表只给这些）。
