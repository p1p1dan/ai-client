同一个任务「修复 Windows 上中文用户名导致登录失败」，左边是现在的样子，右边是按 Claude Code CLI 思路的建议。三种状态可切换，右边每一行都可以点开看详情。所有颜色、字号取自当前设计规范 v2。

建议的五条规则（Claude Code 2.1.307 的实际做法，已从本机安装包核对）
  1. 连续的读文件、搜索合成一行：「搜索了 2 处，读取了 5 个文件」；运行中写成「正在读取…」。点开才看到具体是哪些文件。
  2. 改文件、跑命令等每次一行，后面跟一行结果：改文件显示 +6 −2；跑命令显示结论（通过/失败数、退出码），失败时再露出最后几行输出和「还有 N 行」。
  3. 思考不占行：运行时底部状态行写「✻ 思考中 12 秒」；结束后只在回合末尾留「思考 18 秒」，点开可看原文。
  4. 正文永远直接可见，最后一段标「最终输出」。
  5. 结束后保留这些摘要行（它们本身就是「做了什么、结果如何」），不再收成一排「已工作 ›」。也可以切换成「结束后收成一行」对比。
