#问题选项我的建议

      
1审批卡的差异从哪来A 读当前文件，算出带行号和上下文的差异（Claude Code 的做法）；B 只拿参数里的前后片段（PI-Desktop 的做法）A。能看到在第几行、上下文是什么、全部替换会改几处；覆盖已有文件能看出原来是什么。代价是两个引擎都要改：宿主读文件算好差异，随审批请求一起发过来。读不到时自动退回 B，并写一行说明

      
2卡里的差异要不要「上下 / 并排」切换要；不要，卡里一直上下不要。卡跟输入框一样宽，并排太挤；想细看批准后去审查面板

      
3卡里的差异多高差异自己限高另滚；不单独限高，跟卡片正文一起滚跟正文一起滚，只有一个滚动区。没改的长段落照对话里的做法折成「⋯ N 行未改动」

      
4审批卡上也放「复制补丁」吗放；不放放，所有差异标题一种画法

      
5只有参数片段（没行号）时的复制照样给，提示里写明不能直接应用；不给按钮照样给。贴给人看还是有用，比框选（会丢 +/- 和折叠行）强

      
6审查面板顶上加「复制全部补丁」（所有文件一份）这次做；以后再说以后再说，这次只做单个文件

      
7很大的新建 / 覆盖（几千行）—卡里最多显示 400 行，下面写「还有 N 行未显示」；不影响批准

    

    
框选复制时 +/- 不带上、折叠行漏掉的问题（07.9）这次不动框选本身，用「复制补丁」解决。
