R2 工具输出「复制全部 / 查看全部」（台账 05.3）

现状

命令、读文件等工具展开后，输出放在一个限高的小窗里（命令约半屏高），只能在小窗里滚动或手动框选复制；长输出既看不全也复制不全。按 2026-10-30 的裁定，这次只做「复制全部」「查看全部」，搜索、导出、stdout/stderr 分开放到以后。

① 展开后的输出：右上角「复制」，超出小窗时底部出现「查看全部」

「复制」复制这条工具记录里的全部输出（不是小窗里看得见的那一段）。底部一行写总行数；只在输出超出小窗时才有「查看全部」。

输出： 复制按钮：
运行pnpm vitest run src/renderer· 312 行
已省略前 48 KB

        

          
        

        

      

    

    
开头被引擎省略时（DeepSeek 引擎只留长命令输出的结尾），复制的是手上有的那部分，按钮悬停写「复制全部输出（开头已被省略）」，弹窗顶上同样写「已省略前 48 KB」。不会在复制内容里插入说明文字。

  


  

    
② 「查看全部」打开什么

    

      
      
    

    

      
大弹窗，带行号、整段可滚动，标题写工具和参数，右上角同样有「复制」和关闭；Esc 关闭，焦点回到「查看全部」。在 ① 里点「查看全部」可以打开看效果。

    

    

      
在右侧编辑器开一个只读标签页「输出 · pnpm vitest…」。好处：编辑器自带 Ctrl+F 搜索、能和文件并排；代价：要新做「只读虚拟文档」这种标签，改动大一些，且关掉对话后标签还在。

      

        
split-r2.txt输出 · pnpm vitest run src/renderer

        
查找 ▢ 0/0

      

    

  


  

    
需要你定的

    

      
问题选项

      
「查看全部」打开什么A（推荐）：弹窗。改动小，看完就关。
B：编辑器只读标签页，自带搜索，但要新做一种标签。

      
「复制」按钮A（推荐）：展开后一直显示在输出右上角。
B：鼠标移到输出上才显示（更安静，但键盘和触屏不好找）。

      
运行中的命令A（推荐）：运行中不放这两个按钮，结束后才有（运行中输出还在变，复制到的是半截）。
B：运行中也能复制当前已有的输出。
