建议

建议的规则
  • 换目录本身不弹审批卡，换到工作区外也不弹：它不读不写，也不扩大权限。之后在工作区外读文件、跑命令，照常按「访问工作目录之外」询问（右侧「切到工作区外」能看到这张卡）。
  • 时间线上一行「切换目录 → 路径」，下面一行结果；失败写原因。目录被删时 DSH 自动退回工作区，这一行用轻量通知写明。
  • 当前目录和工作区不同时，输入框下的工作区旁多一个次要标签；在工作区外时标签用警告色，写全路径。回到工作区就消失。另一个选项是不常驻显示、只看时间线，代价是滚走之后看不出模型在哪儿干活。
  • 工具行的路径：模型在子目录里写 src/main.ts，推荐显示成相对工作区的 packages/web/src/main.ts，换来换去也不会认错；在工作区外显示完整路径。点开文件按「调用那一刻的目录」解析。另一个选项是照模型写的原样显示，更短，但同名文件分不清。
  • 左侧的问题：换目录的行显示成通用的「工具 working_directory」；看不出当前目录；点相对路径会按工作区去找，打开错的文件或找不到；权限判断也按工作区算（这一条在第 2 阶段修，界面上看不出来）。
