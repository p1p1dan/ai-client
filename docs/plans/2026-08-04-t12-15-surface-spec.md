## 0. 地基事实（已三方核实）

- **F-a**：ContextPanel 单 view 渲染（`ContextPanel.tsx:51,141`）——切 surface 会 unmount 前一个 view；「常挂载」仅覆盖同 surface 的关/开。
- **F-b**：面板关闭时内层内容列保持最后打开宽度 ≥380px（`ContextPanel.tsx:66-71,102-110`）——xterm/Monaco 不会见到 0 宽。须补不变式测试钉死。
- **F-c**：面板根挂捕获态 Escape（`ContextPanel.tsx:91-96`），会吞 terminal 里 vim/less 与 Monaco find/suggest 的 Esc——**P0，S0 先修**。
- 旧壳保活先例：`MainContent.tsx:577-590` 用 `invisible pointer-events-none`（visibility 隐藏保留布局盒）保 TerminalPanel 挂载——keep-alive 隐藏必须用此技法，**禁用 display:none**（0 宽会经 ResizeObserver 把 cols:2 推给 pty，`useXterm` 无 0 宽守卫）。
- git query-key 缺陷（双轨同发现）：`useGitStatus` 键用 `normalizePath(workdir)`（win/mac 折小写），`useSourceControl.ts:136-142` 的 mutation 失效键用裸 workdir——win/mac 上 commit 后 status/圆点不失效。
- `DiffViewer.tsx:1212-1213` 硬编码永远并排 diff（breakpoint 0）——380px 下两个 ~180px 列不可用。
- 阅读栏现值 45rem/60rem（D25 后），勿回写旧值 48/64。

## 2. T-12 git surface

- **摘件重组不整搬**（双轨一致）：新建 `workspace-shell/surfaces/GitSurfaceView.tsx` + `gitSurfaceModel.ts`。复用 `ChangesList`、`CommitBox`、`DiffViewer`（全 prop 驱动零改动，除下述可选加法）。**不纳入** SourceControlPanel / RepositoryList / CommitHistoryList / BranchSwitcher（最小集纪律）/ `components/git/` 孤儿件。
- 布局：标准态**单视图推入切换** list⇄diff（h-9 子头：diff 态返回箭头 + 截断文件名）；`expanded` 态**两列**（左 Changes+Commit，右 Diff）。纯函数 `deriveGitSurfacePresentation({expanded, selection}) → 'changes'|'diff'|'split'`。**禁止自动 expand**。
- **DiffViewer 可选加法**：`sideBySideInlineBreakpoint?: number`（默认 0=现行为），T-12 传 700；旧宿主不传。
- workdir：`resolveGitWorkdir(chatSessions 快照) → {workdir}|{reason:'no-session'|'no-path'|'not-git'}`（gitEnabled 门），诚实空态。
- **gitQueryKeys 工厂**（T-12 首个子片，Codex 方案）：`gitQueryKeys.status/fileChanges/fileDiff/log(workdir,...)`，内部统一 `normalizePath`；`useGit.ts` + `useSourceControl.ts` 全部改走工厂，禁止手写 `['git',...]`。修复 win/mac commit 后圆点不刷新。单测覆盖大小写/反斜杠/尾斜杠等价路径。
- 刷新：`useFileChanges(workdir, surfaceActive)` / `useGitStatus(workdir, surfaceActive)`（`surfaceActive = activeSurfaceId==='git'`，与 rail dot 共享缓存键）；`useFileDiff` 必须显式 `enabled: surfaceActive && view==='diff'`（其 2s 轮询无 isActive 门），结果经 props `diff` + `skipFetch` 传入 DiffViewer 防双取。
- 纯函数断言面：`partitionFileChanges`（staged 分组/rename originalPath/truncated 透传）、`reduceGitSurfaceView`（select→diff；back→list 清 selection；workdir-changed→list；选中文件 gone→回 list）、`deriveGitSurfacePresentation`、`resolveGitWorkdir`。

## 4. T-14 context surface

- 新建 `surfaces/ContextSurfaceView.tsx` + `contextSurfaceModel.ts`（纯）+ 邻接 store `stores/sessionRuntimeFacts.ts`。**红线 chatSessions.ts 零改动**。
- **permissionMode 协议可选加法**（Codex 方案，T-20 先例，不 bump 版本）：`SessionCreatedEvent/SessionResumedEvent.payload += permissionMode?: SessionPermissionMode`；`claudeRuntime.ts` 建单一常量 `CHAT_PERMISSION_MODE`（同时喂 SDK options 与事件，杜绝双真相）；`claudeRuntimeOptions.test.ts` 断言两者同源。Renderer 由 `sessionRuntimeFacts` 监听收存；未报告时显示诚实空态「Permission policy not reported」，**禁止 UI 写死 default**。
- **实际模型**：优先复用 `messageMetadata` 注册表（byMessage + bySessionLastAssistant）为唯一真相；若其不可订阅（施工时核实），把 actualModel 一并收进 `sessionRuntimeFacts`（单监听器），**不得两处存同一真相**。显示优先级 actual > configured，二者不同时并列显示并标注来源。
- 字段表（全部真实来源，缺失即整行不渲染，组内全空剔组）：三组 —— **Workspace**（路径[title 全值+可复制] / kind / branch[缺失不渲染，不回落猜名] / gitEnabled===true 才显示）；**Runtime**（configured 模型 `resolveResumeModel` / actual 模型 / effort `getSessionEffort`→label（null='Default' 真语义）/ 权限策略[事件真值] / Host `useHostStatus`（state/pid/driver/版本；stopped 也照显））；**Session**（`session.status` 9 态原样 + `retry` 详情 + `turnSendStatus` phase/elapsed / 待答授权数[按 sessionId 过滤] / Sent attachments[逐消息展平 kind/name，不去重不显 data，@ 引用另列 mentions] / runtimeIdentity）。
- **明确不做**：Quick notes / Plans（无数据源，做即假状态）；Todo（有 store 但超 0.5d 口径，登记后置）。
- 布局：纵向滚动 definition list，行 h-7，label `text-meta text-muted-foreground shrink-0`，值 `min-w-0 flex-1 truncate text-ui` + title。
- 纯函数断言面：`deriveContextGroups`（含「零硬编码占位」反向断言）、`deriveRunState`（9 态全覆盖 + retry + turnSend）、`deriveSessionReferences`、`reduceSessionRuntimeFacts`（缺字段不覆盖已有真值；session 隔离）。

## 5. T-15 terminal surface

- **keep-alive 挂载**（Codex 方案，补全 T-22「为 T-15 保挂载」本意）：`terminal` 注册 `mountPolicy:'keep-alive'`——首次激活后常驻（S0 机制），切 surface / 关面板都不 unmount，pty 天然存活。**不采** detach/attach 重连主案（replay 64KB 上限/焦点/重复输出代价；`persistOnDisconnect` 不动）。
- **复用 `TerminalPanel` 整池**（含 `WorktreeGroupStates` per-worktree 恢复、tab/split、全局 store 同步——旧壳实战件；新旧壳互斥不会双实例）。**不建新薄池**（避免第三套所有权），**不碰 `quickTerminalSessions`**。
- `TerminalSurfaceView`：解析 workspace path → `TerminalPanel cwd={path} isActive={activeSurfaceId==='terminal'} presentation={expanded?'full':'compact'}`。`TerminalPanel` 加可选 `presentation?: 'compact'|'full'`（默认 full=现行为）：compact 只显 active group、split/merge/跨组拖拽 disabled+Tooltip「Expand the panel to manage terminal splits」，tab 条横向滚动；新建/关/切/搜索/输入可用。
- 纯函数断言面：`deriveMountedSurfaceIds`（S0）、`deriveTerminalPresentation`、`visibleTerminalGroupIds`（compact 仅 active 组、缺 activeGroupId 回落首组）、`canManageTerminalSplits`。
- 验收必须含：terminal 跑 `sleep 30` → 切 git → 切回，进程仍在输出连续；切 Workspace A→B→A 恢复 A 的 groups/tabs。
- 已知限制登记：应用重启后 pty 不复活（与旧壳一致）；`isActive` 翻真时 `terminal.focus()` 抢焦点（用户主动选择，接受）。
