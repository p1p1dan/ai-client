#12 / #13Theme

#15 / #22Network

缓存亲和与网络瞬断待现场复测

需同模型对照、网关采样与真实频率观察；app 已补重试可见性但不能根治传输瞬断。

#1Decision

#6 / #23 / #24Product

归档恢复、Permission Dock、标题来源元数据

均已确认是独立产品/数据建模缺口，尚未进入当前实现批次。

#17 / #21Architecture

Subagent 数据源与消息队列后续

建议先读磁盘 subagents 回放；队列仍有失败退避、后台放行、持久化等二期设计。

#20 / #26Reliability

stopping 直发边界与 Host clientTurnId 幂等

当前不阻塞验收，但都是竞态与重复发送的纵深防御候选。
