# 决策 049：委派定义里声明的权限档位，在 DSH 下按 inherit 处理

日期：2026-09-27。**状态：自主决定，待用户审批。** 依据：[P1-6 方案 §5 D11](../topics/p1-6-permissions.md#5-需要拍板的决策点)。

## 规则

1. 1.0.x 允许自定义子代理在委派定义里声明档位（单独降档或升档）。DSH 的代理预设没有这个字段，所以在 DSH 下一律按 inherit 处理，也就是与根会话同档。
2. 相关的 3～4 条用例判 N/A，去留交给 P1-7。

## 取舍

- 不选「P1-6 自己给 DSH 的代理预设加字段」：要改 DSH 的预设格式，升级时要重做。
- 代价：自定义子代理不能再单独改档位。
