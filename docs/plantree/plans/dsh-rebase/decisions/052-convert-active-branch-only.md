# 决策 052：迁移只转换 pi 会话的活动分支；旁支转 lineage 列为可选的 P1-9h

日期：2026-09-27。**状态：自主决定，待用户审批。** 依据：[P1-9 方案 §5 D3](../topics/p1-9-migration.md#5-需要拍板的决策点)。

## 规则

1. 迁移时只转换活动分支（当前 leaf 所在的那条链）。
2. 旁支不转换，原文件里仍然保留，回装 1.0.x 后还能看到。
3. 可选子任务 P1-9h 在 P1-4b 之后，把旁支转成退役的 DSH 会话，挂进 lineage，可以放到合入之后再做。

## 取舍

- 1.0.x 的历史本来就只显示活动分支。
- 旁支多时，全部转换会让存储成倍增长，而且依赖 P1-4b 的 lineage 与树。
- 代价：DSH 构建的树对话框里，看不到迁移前的旁支。
