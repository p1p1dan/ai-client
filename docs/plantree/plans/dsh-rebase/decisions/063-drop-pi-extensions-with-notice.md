# 决策 063：pi 扩展在 DSH 构建里不再加载，插件页只读列出并提示（请重点审批）

日期：2026-09-27。**状态：用户 2026-09-28 裁决（见[决策 090](090-user-rulings-2026-09-28.md)）。** 依据：[P1-10 / P1-16 方案 §5 D12](../topics/p1-10-p1-16-extensions.md#5-需要拍板的决策点)、[Q003](../open-questions.md)（内嵌终端去留，P1-11）。

## 规则

1. 1.0.x 起，聊天本来就不加载 pi 扩展，只有内置的 pi 终端加载（`piPlugins/index.ts:111-119`）。P1-12 删掉 `resources/agent-host` 之后，就不再有 pi CLI 这个载体。
2. 「扩展→插件」页改为 DSH 白名单插件列表；1.0.x 装过的 pi 扩展在下方只读列出，注明新版不再加载。文件不动，回装 1.0.x 后照常可用。
3. **如果 P1-11 决定保留 pi TUI**，就改为 B：pi 扩展在 TUI 里照常加载，本决策随之修订。

## 取舍

- 代价：在内置终端里用 pi 扩展的用户会失去它们。
