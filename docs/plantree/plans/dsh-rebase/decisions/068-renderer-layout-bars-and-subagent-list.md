# 决策 068：输入框上方叠三条可折叠窄条（待办 → 目标 → 后台），子代理保留行内泳道并在运行面板加清单（界面布局，开工前出原型请用户确认）

日期：2026-09-27。**状态：自主决定，待用户审批。** 依据：[P1-7 方案 §5 U1、U2](../topics/p1-7-renderer.md#5-需要拍板的决策点)、runtime-hardening 决策 038（委派两层）、[分片 03](../topics/p1-7-renderer/03-panels.md)。

## 规则

1. 输入框上方按「待办 → 目标 → 后台」的顺序叠三条可折叠窄条，与 DSH 的顺序一致，与 09-24 用户认可的后台任务条同形。
2. 子代理：保留行内泳道（决策 038 的委派两层），另在左栏「运行」面板加「本会话全部子代理」清单。
3. **P1-7a 开工前先做一张原型页，给用户确认布局。** 原型就是验收基准；用户改了布局，按用户的来，本决策随之修订。

## 取舍

- 不选「一行状态小标，点开浮层」：目标状态不能一眼看见。
- 不选「只放左栏运行面板」：运行面板收起时什么都看不到。
- 不选「子代理另开左栏 surface」：与委派两层重复。
- 代价：三条同时出现时，多占约 84 px；运行面板收起时看不到子代理清单。
