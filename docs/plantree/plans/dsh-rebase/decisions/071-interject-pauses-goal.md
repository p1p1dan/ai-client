# 决策 071：目标运行中按 Ctrl+Enter 与普通回合一致：本轮在步边界结束，目标暂停

日期：2026-09-27。**状态：用户 2026-09-28 批准（[决策 090](090-user-rulings-2026-09-28.md)）。** 依据：[P1-7 方案 §5 U5](../topics/p1-7-renderer.md#5-需要拍板的决策点)、[决策 029](029-interject-keeps-v103-semantics.md)。

**修订（2026-09-28，P1-4c1）**：被[决策 093](093-interject-via-dsh-steer.md)（用户已批准）取代。插话并入当前回合，目标不暂停，目标条不再需要「因插话暂停」的状态；已随 P1-4c1 落地，见[决策 111](111-p1-4c1-turn-semantics-choices.md)。

## 规则

1. 目标（goal）运行中按 Ctrl+Enter 插话，与普通回合相同（决策 029）：本轮在步边界结束，插入的消息作为下一回合输入。
2. 目标因这次取消而暂停，目标条上给出「继续」。

## 取舍

- 不选「目标轮里改用 DSH 的 steer，消息并入当前轮、目标不停」：语义与普通回合不一致，可以作为后续增强。
- 代价：想边跑边补一句时，目标会停下来，要多点一次「继续」。
