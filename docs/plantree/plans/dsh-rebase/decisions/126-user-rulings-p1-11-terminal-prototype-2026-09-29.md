# 决策 126：用户对 P1-11 右列终端原型（场景 G）的裁决（2026-09-29）

日期：2026-09-29。**状态：用户裁决。** 依据：用户对原型场景 G（[p1-7-prototype-2026-09-28/](../evidence/p1-7-prototype-2026-09-28/) 的 `prototype.html` 场景 G、`shots/G-terminal-*.png`，提交 `3c47c0b1`）三个问题的答复：「都同意」。

## 裁决

1. **终端与文件编辑器共用右列、二选一显示。** 会话栏的「终端」按钮在右列打开该会话目录下的普通 shell，文件编辑器让出列位；关掉终端，原来的文件标签原样恢复。实现复用右列现有的编辑器 / 审阅互斥机制（`WorkspaceShell.tsx` 的 `editorOpen` / `reviewOpen`，共享 `--shell-editor-w`）。
2. **会话没有绑定目录时，终端按钮置灰。** 不退回到用户主目录开 shell。
3. **终端列宽沿用文件编辑器列现成的拖拽宽度机制**，不另定一套；默认约 460 px。

## 落实

- P1-11 按本决策与[决策 109](109-user-rulings-p1-7-prototype-2026-09-28.md) 开工：pi TUI 与会话栏 GUI / TUI 开关去掉，换成右列普通 shell 终端。
- 原型 README 第 10 题（会话未绑定目录时的终端）由第 2 条定下。
- 原型里 C / D / E 场景的历史截图仍显示旧的子代理名，不再重出；以决策 119 第 25 条为准。

补记（2026-09-29）：实现见[决策 128](128-p1-11-right-column-terminal-choices.md)（待审批）。第 3 条按「沿用编辑器列的拖拽宽度机制」落实后，默认宽度是中栏的一半（默认侧栏下 1440×900 为 558 px、1280×720 为 520 px），不是原型静态占位的 460 px，见 128 第 7 条。
