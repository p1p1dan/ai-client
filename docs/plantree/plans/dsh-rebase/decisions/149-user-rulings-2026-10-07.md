4. **E8 缓解选 A**（[决策 150](150-e8-plugin-credential-isolation.md) 第 2 节）：只加审查判据与静态守卫，运行期行为不变。三条必拒判据：出现 `ctx.credentials` / `ctx.get('credentials')`；出现 `process.on('message')` / `prependListener` / `process.send` / `removeAllListeners('message')`；出现 `Symbol.for('cordis.original')` 或对 `ctx.get(...)` 返回对象、`Module`、全局、`process` 的属性赋值。B（按调用方放行）不做；D（Main 本地反代，key 不进宿主）记为长期方向，不在 P1。
