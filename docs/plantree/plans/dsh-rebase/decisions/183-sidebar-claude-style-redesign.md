# 决策 183：「聊天」侧栏改版（参考 Claude 桌面版）——去掉「正在活动」区与板块标题，临时对话成为置顶分组，五个面板去掉标题栏

日期：2026-10-11。**状态：全部已定。第 1 节为用户裁决（2026-10-11 对话中看预览 v1～v5 的答复）；第 2 节为自主决定，其中第 14、16 条由用户改定，其余用户 2026-10-11 批准（「其余就按你的来」）。**

来源：用户在对话里提出（不是 GitHub issue）：「左侧栏目的样式还是需要适当调整一下，不需要临时对话和正在活动了。临时对话就作为一个固定的文件夹；正在活动有些多余了，就在仓库列表中以现有光标形式区分运行和非运行状态即可。可以参考这个 Claude desktop 的样式……其中有些功能按钮按我们自己的来。」附 Claude 桌面版侧栏截图。

**验收基准是原型**：[`evidence/sidebar-claude-style-2026-10/prototype.html`](../evidence/sidebar-claude-style-2026-10/README.md) 的默认视图（v5 定稿；工具条只剩主题与「『聊天』面板标题」两个开关，后者默认「去掉」即定稿）。原型里 `.vB` 一套样式是 v1 的对比项，已否决，不实现。

## 1. 用户裁决（2026-10-11）

1. **去掉「正在活动」区**。运行状态只在仓库列表每一行行首的状态槽里看，沿用现有标记（转圈、橙点、绿点、红点、空心圈）。
2. **「临时对话」不再是独立的一区，变成列表里的一个固定分组**，**置顶**（在所有仓库之前），不参与按活动排序。
3. **分组名用参考图的灰色小字标签**（14px、400、`muted-foreground`、无文件夹图标），不用 #6 的「文件夹 15px 600 正文色 + 黄色图标」。这推翻决策 170 第 1 节 issue #6 裁决 2 的「板块 16 → 文件夹 15 → 对话 14 逐级变小」——用户在预览里两种并排看过后选的。
4. **行尾相对时间默认隐藏**。悬停（或键盘焦点在行内）时，右侧浮出「归档 / 从列表移除」（临时工作区的行多一个「删除」），浮在行上、不挤标题。
5. **空仓库不显示「＋ 新建对话」辅助行**，只留分组标题（悬停标题出「＋」）。
6. **分组标题的小三角**：折叠时常显 ▸；展开时只在悬停时显示 ▾（v3 试过展开也常显，用户说「好乱」，撤回）。
7. **未启动的对话也显示空心圈**，颜色比「后台已挂上」的空心圈更淡，每一行行首都有标记、对齐统一。
8. **「全部折叠」是开关**：有任一分组展开时点它全部折叠；全部已折叠时按钮变成「全部展开」，再点全部展开。
9. **去掉左栏五个面板（聊天、Git、文件、终端、运行）共用的标题栏 `DockTitle`**，面板内容直接从顶部开始。用户先要看保留的样子，看过后说「五个页面可以都去掉」。
10. 整体排布按原型：顶部竖排导航（新建对话、添加仓库）→ 一行搜索框 + 全部折叠 + 批量归档 → 分组列表（无「仓库列表」标题，分组之间靠留白）→ 账户栏。
11. **三个区之间加通栏细线**（2026-10-12，看过本机开发版后提出「上栏、中栏、下栏界限不明显，乍一看用户那块也像个对话」；预览 v6 并排比较后选定）：顶区（导航 + 搜索行）下面一条、账户栏上面一条，1px `border` 色、通栏；其余地方仍不加线。
12. **账户栏照原型 32px**：行高 32px、头像 22px；**不再直接显示今日用量**（用户：「容易给人压力」），用量只在点开的账户卡片里看。

## 2. 自主决定（用户已批准）

1. **搜索框常显，去掉「筛选会话」开关按钮**（原型如此）。`searchVisible` 状态与开关按钮一起删除。
2. **折叠的分组在名字后显示汇总标记**：组内有在跑的显示转圈（多于 1 个时带数字），有等你审批 / 回答的显示橙点，有失败未看的显示红点、否则有结果未看的显示绿点；展开时不显示（行首已有）。理由：去掉「正在活动」后，折叠会把运行状态藏起来。原型里有，用户看过 v1～v5 未提异议。
3. **分组标题不再显示主工作区分支**（「main」等）；名称 / 主工作区分支 / 远程 三行悬停提示照旧。改动合计（+N / −N）保留，悬停时让位给「···」与「＋」（与现在同一个 grid 格）。
4. **对话行不再缩进**（原型 A 版没有 `pl-3`）：分组标题文字与行首状态槽左缘对齐。
5. **未启动的淡空心圈**用一个派生颜色 token（`muted-foreground` 向侧栏底色混合约 45%，不带 `/N`），只在 `:root` 声明一次，亮 / 暗 / 同步终端主题都跟着走；写法同 `--foreground-soft`。
6. **隐藏时间后，绝对时间仍在行的悬停提示里**（决策 167 §3 的「YYYY-MM-DD HH:MM」）。
7. **面板去掉标题后，面板容器带 `aria-label`**（面板名），读屏仍能知道在哪个面板；看得见的「在哪」由导轨高亮承担。
8. **账户栏去掉上边线，行尾加 `ChevronsUpDown`**（原型如此，表示可展开账户菜单）。
9. **临时对话分组**：标题悬停出「＋」= 新建临时对话（回首页、「不选仓库」，决策 174）；右键菜单「新建临时对话」保留；它也受「全部折叠 / 全部展开」与「查看更多」约束。没有临时对话时整组不渲染。
10. **列表空白处的右键菜单**（原「仓库列表」区的「添加仓库」）保留在整个列表区上。
11. **仓库排序不变**：按组内最近一个对话的活动时间排序，指针或焦点在列表里时不重排（决策 170 第 1 节裁决 6）；只是临时对话组固定在最前，不参与排序。
12. 「正在活动」相关的状态、词条和派生（`renderActiveRegion`、5 条上限与「查看更多」、收起开关）随区一起删除；「后台已挂上」的空心圈、未读圆点、待审批徽标等行级状态不变。
13. **悬停才出现的东西只认鼠标悬停与键盘焦点（`focus-visible`），不认点击留下的焦点**：行的浮出操作、分组标题的「···」「＋」与让位的改动合计、展开时的 ▾。否则点过一行或一个分组标题后，鼠标移开按钮仍一直浮着。Tab 仍能让操作出现，键盘可达。
14. **搜索时忽略折叠状态**：搜索词非空时，有匹配的分组一律展开显示；**清空搜索后，最后一次搜索匹配到的分组保持展开，不恢复原来的折叠**（用户裁决 2026-10-11；打字过程中只被中间前缀匹配到的分组不算），其余分组保持原状；「全部折叠 / 全部展开」按钮置灰（文案按不搜索时的折叠状态算，不随搜索变）；搜索期间点分组标题不折叠，免得悄悄改掉存下来的折叠状态；没有匹配的分组照旧隐藏。原型如此；不这样的话，折叠着的分组会把搜索结果藏起来。
15. 实现时照原型补的几处：辅助行（查看更多 / 收起）`h-6` → `h-7`（原型 28px）；导轨顶部原为对齐 `DockTitle` 的 `h-9` 占位改为 `py-2`（导轨首个图标与「新建对话」差 2px，原型同）；分组标题键盘聚焦时有 `bg-hover` 底色（鼠标悬停仍无底色，原型未定义焦点样式）；多选栏文字 `text-meta`。
16. ~~搜索框沿用 coss `InputGroup` 的默认外观~~ → **用户裁决（2026-10-11）改为照原型**：在预览里并排看过「原型（透明底细线）」与「coss 默认」后选原型。仍用 coss `InputGroup`，只在这一处用类覆盖：静止时透明底、`border` 色 1px 细线、无阴影；聚焦时 `bg-background`、线变 `muted-foreground`、无主题色光环。
17. 淡空心圈 token 名 `--muted-foreground-faint`，值为 `muted-foreground` 向侧栏实际底色（`bg-card/40` 叠在 `bg-background` 上）混合 45%，约亮色 `#AEACA6`、暗色 `#53514E`，对侧栏底约 2.2:1。有意低于正文对比度要求：它是装饰标记（`aria-hidden`），含义在行的悬停提示里。

## 5. 现场清单（测试包上对照原型看）

1. 对话行悬停：浮出的「归档 / 从列表移除」底色与向左渐隐，普通行与选中行各看一次；点过一行、鼠标移开后按钮不应留着；Tab 能让按钮出现。
2. 折叠的分组：名字后的转圈（带数字）、橙点、红 / 绿点；展开时 ▾ 只在悬停时出现，点过标题后不留着。
3. 淡空心圈：亮色、暗色、同步终端主题下可见但比「后台已挂上」淡。
4. 搜索：折叠着的分组有匹配时展开显示，清空后恢复原折叠；搜索中「全部折叠」置灰。
5. 顶部：导轨首个图标与「新建对话」的 2px 差；Git / 文件 / 终端 / 运行四个面板没有标题栏后顶部是否正常。
6. 搜索框（coss 默认外观）与原型的差距是否可接受；账户栏的 `ChevronsUpDown`；查看更多 / 收起 `h-7`。
