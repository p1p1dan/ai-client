# 决策 211：运行中的回合只说一次自己在做什么

日期：2026-11-09（北京时间）。

**状态**：方向由用户 2026-11-09 的要求定下（第 1 节），终端式的细节照 Claude Code 终端版的代码，桌面式照用户给的两张桌面版截图（第 2 节）。第 4 节标「自主」的各条待用户审批。

**代码**：main `7b74dac6`，和[决策 212](212-subagent-one-line.md) 同一个提交；2026-11-09 推送，进 v1.2.3（没出测试包）。

**修订关系**：

- [决策 208](208-chat-transcript-styles.md) §3.2 第 3 处「运行中的那一行」：终端式不再固定在回合末尾另起一行，改为挂在正在进行的那一行上；没有这样的行时才单独一行。
- PiLab R1（2026-10-30）「回合末尾的实时行」同上；计时写法从「12 秒」改为 `12s`。

## 1 现象

用户 2026-11-09 附了一张开发版截图（终端式），原话：「在终端显示模式下，最后一行还是存在重复状态显示的问题，如图，最后一行输出显示 thinking，底下还有个状态栏显示 思考中..(10分 37 秒·esc 中断)。按我的想法，就应该直接是在 thinking 那个位置按思考中这个方式状态显示：thinking.. (10h 37 s · esc 中断)，不需要这个思考中的状态栏了」。

截图末尾两行：

- `∴ Thinking...`：正在流的思考；
- `· 思考中... (10 分 37 秒 · esc 中断)`：回合末尾的实时行。

两行说的是同一件事。

随后补充：「我指的不仅仅是思考行。而是所有状态，思考只是恰巧我截图时的一个情况」。又附了两张桌面版截图：「可以参考（不一样非要一样，我们可以做的更好）。终端版本就去参考终端的代码」。

看过第一版之后又说：「怎么又有思考中又有 thinking？肯定得统一啊」。第一版里，思考行写 `Thinking…`，两步之间单独那一行写「思考中…」；状态在两者之间来回移动，同一件事换着两种语言说（第 3.5 节）。

同样的重复也出现在命令运行时：

- 终端式：`● Bash(跑测试)` 加 `⎿ Running…`，底下又有 `✻ 跑测试… (12 秒 · esc 中断)`；
- 桌面式：折叠行在流光里写着 `Bash 跑测试`，底下又有 `✻ 运行中 12 秒`。

## 2 查证

### 2.1 终端版（Claude Code 2.1.273 拆包，`F:\projects\tmp\claude-cli-research\extracted\readable`）

- **底部动画行**：`✻ <动词>… (12s · ↓ 1.2k tokens · thinking)`。
  - 动词是每轮随机挑的（或进行中待办的 `activeForm`），不随状态变。
  - 括号里依次是回合用时、token 数，思考时再加 `thinking`。
  - 星号在 `· ✢ * ✶ ✻ ✽` 之间来回切换，品牌色（`chunk-24z06dv8.js`，`YKt` / `so`）。
- **思考**：流的时候，记录里没有思考行，只有动画行括号里写 `thinking`。思考结束后，记录里出现折叠行，进行中写 `Thinking for Ns…`，结束写 `Thought for Ns`（`chunk-sxzztw5t.js:10643`）。`∴ ∷ ∵ ∷` 那组帧在这个版本里没有用到。
- **命令运行**：
  - 命令行写 `⏺ Bash(…)`，圆点灰色闪烁；
  - 下一行写 `⎿ Running…`，两秒后带上命令自己的用时，如 `(5s · timeout 2m)`；
  - 底部动画行同时还在，动词不重复命令的说明。
- **回复正文流出来**：第一行完整文字出现后，底部动画行隐藏；正文落定后再出现（`chunk-c5xn880r.js:89264`）。
- **中断提示**：`esc to interrupt` 在输入框下面的页脚，不在动画行上。
- **进行中与结束**：进行中的折叠行用正文色，结束后变暗。

### 2.2 桌面版（用户 2026-11-09 的两张截图）

底部只有一行在动，这一行就是正在做的事，回合计时挂在它上面：

- 思考时：`··· 4m 0s · 633 tokens · Thinking`；
- 读文件时：`Reading MessageTimeline.tsx 4m 18s · (3100–3189, …) ›`。

`4m 0s` 到 `4m 18s` 是同一个回合连续计的时，不是这一步自己的用时。没有另一行重复说。

## 3 改法

### 3.1 原则

运行中的回合，计时和「esc 中断」只出现一次：

- 挂在最后那条正在进行的行上；
- 没有正在进行的行时（刚发出去、两步之间等模型），才单独画一行；
- 回复正文流出来时，不画单独那一行，照终端版。

由回合的最后一组步骤（`ToolGroup`）决定挂在哪一行：它手里有这些行。回合（`ChatTurn`）给这一组打上标记（`TurnLiveSlotContext`），自己就不在末尾画了。最后一项不是步骤组时（正文、提示），仍由回合在末尾画。一处决定，所以不会两处都画，也不会两处都不画。

### 3.2 终端式

- **思考流出来**：`✻ Thinking… (10m 37s · esc 中断)`。
  - 行首换成原状态行那个会动的品牌色 ✻；
  - `Thinking…` 用品牌色、正体，和原状态行一样；
  - 括号里是浅灰；
  - 思考结束后恢复成 `∴ Thought for 51s`。
- **命令运行**：`✻ Bash(跑测试) (12s · esc 中断)`。
  - 工具名和说明用品牌色；
  - 下面照旧是 `⎿ Running…` 或实时输出；
  - 结束后行首恢复成按结果着色的 ●。
- **几条同时在跑**：只挂在最新的那条上，其他照旧是闪烁的灰点。
- **特殊行**：待办清单、审查结论有自己的画法，不挂；状态单独一行，接在它后面。子代理行见[决策 212](212-subagent-one-line.md)。
- **没有正在进行的行**：单独一行 `✻ Thinking… (12s · esc 中断)`，位置和原来一样，在最后一步后面。和思考行挂上状态时一模一样。
- **回复正文流出来**：不画。

### 3.3 桌面式

- **正在跑的那一段**：行首是转动的状态图标，然后是这一步的字（流光），最后是回合计时 `4m 18s`，同桌面版截图。
- **没有正在跑的段**：单独一行，转动图标加 `Thinking… 12s`。原来行首还有一个 `✻`，和图标重复，去掉了。
- **回复正文流出来**：不画。

### 3.4 计时写法

正在运行的回合，计时一律写 `12s`、`4m`、`4m 18s`，和思考行的 `Thought for 12s` 同一种写法：

- 挂在行上的、单独那一行、桌面式段尾的，都用这一种；
- 状态在行与行之间移动时，计时的样子不会变来变去；
- 回合结束后的账单（「完成于 … · 用时 1 分 5 秒」）不变。

### 3.5 用词（用户 2026-11-09：「肯定得统一啊」）

运行中的回合说自己在做什么，一律用英文，和思考行的 `Thinking…`、终端版的动词一样，不翻译：

| 状态 | 原来 | 现在 |
|---|---|---|
| 刚发出、连接引擎 | 正在连接对话引擎… | `Connecting…` |
| 等模型、思考 | 思考中 | `Thinking…` |
| 回复在写 | 回复中 | `Replying…` |
| 兜底 | 工作中 | `Working…` |
| 某个工具在跑、又没有行可挂 | 这一步的说明或动词 | 不变，说明照原文，动词用英文（`Running…`） |

- 括号里的 `esc 中断` 照旧是中文，用户给的例子就是这样写的。
- 发出后、回合回显之前的那一行（`PendingTurnHead`）原来自己拼字、自己画，现在和回合里那一行用同一个组件。回显前后，这一行的字和样子都不会变。
- 回合结束后的账单「思考 32 秒」是一句中文，不在这次范围内。

## 4 自主决定（待审批）

1. 行上挂的是回合用时，不是这一步自己的用时。
   - 这样跟桌面版截图一致，也跟用户给的例子一致（`10h 37 s` 就是截图里的回合用时）。
   - DSH 命令自带的「12s · 2m 后转后台」照旧显示：它说的是什么时候转后台，回合计时说不了这个。
2. 带状态的那一行画成原状态行的样子：品牌色 ✻、品牌色文字、浅灰括号，结束后恢复。
   - 用户说「按思考中这个方式状态显示」。
   - 终端版进行中的行用正文色，结束变暗，用意相同。
3. 计时改成 `12s` / `4m 18s`，原来是「12 秒」。单独那一行和桌面式也一起改（第 3.4 节）。
4. 回复正文流出来时不画状态行，照终端版。
   - 终端版的 `esc to interrupt` 在页脚，回复时仍看得到。我们没有页脚，回复时要停只能用输入框的停止按钮。
   - 正文还没出字（空白）时照旧画。
5. `esc 中断` 留在括号里：用户给的例子里有。终端版放在页脚。
6. 特殊行（待办、子代理泳道、审查结论）不挂计时，状态单独一行接在它后面。
7. 几条同时在跑时只挂在最新那条上。
8. 桌面式在跑的那一段，行首加转动图标（同桌面版截图里的 `···`）。
9. 终端版思考流的时候不画思考行，只靠动画行括号里的 `thinking`。我们照用户的要求保留思考行，把状态挂上去；思考行仍可点开看正在写的思考。
10. 用词统一成英文（第 3.5 节），连「正在连接对话引擎…」也改成 `Connecting…`；桌面式单独那一行去掉重复的 `✻`。

## 5 实现

- `turnLiveStatus.tsx`（新）：
  - 两个上下文：`TurnLiveSlotContext` 标出回合的最后一组步骤，不随时间变；`TurnLiveClockContext` 放每秒更新的文字，只有叶子组件读。
  - 选行：`liveRowHostIndex`（终端式）、`liveRunHostIndex`（桌面式）。
  - 组件：`TurnLiveTail` 是行尾括号，`TurnLiveRunClock` 是桌面式段尾计时，`TurnLiveLine` 是单独那一行。
  - `replyStreaming` 判断回复是否正在流。
- `ToolRows.tsx`：
  - `ToolGroup` 拿到标记后，把状态挂在最新那条正在进行的行上，或在组尾画单独一行；
  - 组里嵌套的步骤组一律不算（展开的桌面式段、子代理泳道）。
- `MessageTimeline.tsx`：
  - `useTurnLiveClock` 生成文字，原 `useTurnClockLine` 与 `TurnClockRow` 去掉；
  - 回合末尾只在最后一项不是步骤组、且回复不在流时，才画单独一行。
- `turnLiveHead.ts`：`liveClockText` 生成计时；`formatTurnLiveLine` 也负责「工作中」的兜底，`workingHeadText` 去掉。
- `TranscriptBlocks.tsx`：行首圆点多一种 `live`（✻）；`data-turn-live-host` 标出带状态的那一块。
- `chatTimelineLayout.ts`：`terminalLiveTailClass`、`turnLiveClockClass`、`terminalLiveWordsClass`。
- `src/dsh-host/tools/fake-gateway.mjs`：`CC-RUN` 加了三个可选参数 `think`、`thinkMs`、`leadMs`，每一步可以先停一会儿、再慢慢写思考，开发版才看得到各个状态（第 6 节）。

## 7 开发版实测（2026-11-09）

用 `gui-probe.mjs` 起开发版，模型走本地假网关（`--plan claude-sdk`，Agent SDK 引擎），权限设为跳过确认。发一条放慢节奏的 `CC-RUN`：

- 每一步先停 6 秒，再用约 12 秒把思考写完；
- 第一步跑 `sleep 14`，第二步跑 `ls`（桌面式那一轮换成 `Read`），最后回一句话。

每 4 秒截一张图，任何时刻都只有一处状态。

终端式：

- 刚发出：单独一行 `✻ 思考中… (2s · esc 中断)`。
- 思考流出来：`✻ Thinking… (25s · esc 中断)`，品牌色，底下没有另一行。
- 命令运行：`∴ Thought for 11s` 之后是 `✻ Bash(Build the project) (38s · esc 中断)`，下面 `⎿ 运行中…`，右侧「转到后台」。
- 命令跑完、等模型：`● Bash(Build the project) ⎿ built` 之后单独一行 `✻ 思考中… (50s · esc 中断)`。
- 第二段思考：`✻ Thinking… (1m 2s · esc 中断)`。
- 结束：三处都恢复成灰色的 `∴ Thought for 11s`，命令是绿点；账单「完成于 01:03 · 用时 1 分 21 秒 · 2 次工具调用 · 思考 32 秒」。

桌面式：

- 命令运行：`⟳ Bash Build the project 29s ›`，底下没有另一行。
- 思考：`⟳ Thinking… 37s ›`。
- 命令跑完、等模型：`Thought for 11s · 运行了 1 条命令 ›` 之后单独一行 `✻ 思考中 33s`。
- 结束：`Thought for 32s · 运行了 1 条命令，读取了 1 个文件 ›` 和账单。

切换样式在 设置 → 外观 → 聊天区 →「对话显示方式」。

统一用词之后（第 3.5 节）又跑了一轮终端式，即决策 212 那一轮。刚发出和等模型时，单独那一行写 `✻ Thinking… (3s · esc 中断)`、`(8s · esc 中断)`，和思考行挂上状态时用同一个词，不再出现「思考中」。
