# P0-5 收口：P0 结论与 P1 入口（2026-09-26，待用户确认）

Role: evidence。上位：[roadmap P0-5](../roadmap.md)。依据[决策 001](../decisions/001-route-b-and-scope.md)，以及修订它的[决策 002](../decisions/002-defer-encrypted-machine-and-shared-host.md)：P0 平台门槛为 Linux + 普通 Windows，加密机挪到 P2 前。

## 结论

**建议进入 P1。** 按决策 002 修订后的门槛，P0 各项退出判据都已满足，没有触发「回到决策点」的情况。

- 仍带着走的最大风险是加密机：随包 `node.exe` 加载原生 DLL、koffi 命名信号量、ACL 沙箱降权进程能否拿到明文，都还没验证。上机包现成，有机会就提前跑；不过就回到决策点。
- P1 开工前还有一个外部变量：用户 2026-09-26 在自己的 Windows 机上用官方 DSH Desktop + 自家网关的 Claude 试 DSH 驾驭层的效果，以此决定 Claude 模型要不要另加 SDK 引擎（[Q006](../open-questions.md)）。这件事不改变 P0 结论，但会影响 P1 的范围与排期。无论结论如何，P1 的第一项都应该是「按会话选引擎」的接缝，两边都要用。

## 未决问题的处置

- **Q001 进程拓扑**：已由决策 002 定为共享宿主，P0-6 在引擎层验证通过。
- **Q002 沙箱在加密机上能否叠加**：随加密机挪到 P2 前。
- **Q003 内嵌终端**：P2 前定，不变。
- **Q004 版本通道**：建议如下，用户确认后记为决策 003。
  - 事实：2026-09-26 查 npm，`@deepseek-ai/dsh-base` 的 `latest` 仍是 `0.0.1-rc.1`，`@deepseek-ai/dsh` 的 `latest` 是 `0.1.5-rc.3`，两者的 `next` 都是 `0.1.7-rc.2`（09-24 发布）。09-22～09-24 三天连发 alpha.1、alpha.2、rc.1、rc.2。社区插件里有 9 个把 peer 精确钉在旧 rc 上。
  - 建议：P1 钉 `next` 通道的精确版本（开工时的最新 rc，目前为 `0.1.7-rc.2`），锁文件入库，不用范围版本。升级作为单独任务：升版本 → 重跑 P0 回归（`bridge-smoke.ts`、`goal-probe.ts`、`p0-6-probe.ts`、Windows CI workflow）→ 复核白名单插件的 peer → 再合入。P1 期间不追每个 rc，只在需要上游修复或新能力时升级。升级节奏在 P2 定。
- **Q005 Windows ACL 沙箱与工作区权限**：P1 设计权限移植时定。
- **Q006 Claude 模型是否另加 SDK 引擎**：等用户试用结果。

## P1 入口：从 P0 带过来的必做项

以下按来源列出，P1 拆任务时逐条落到 roadmap。

- **引擎接缝**：会话级引擎字段（`ManagedSlot`、会话索引行的 `agent`）、`AGENT_WIRE_NAMES`、4 条拉起路径、设置项。与 Q006 共用，建议排第一。
- **bridge 对等**（P0-3）：
  - 历史、用量、权限档位、goal / todo 事件映射；
  - 逐次审批挂 `tools/pre-execute`；
  - 录制事件流做回归门禁。
- **共享宿主**（P0-6）：
  - Main 侧宿主级崩溃处理：一次重启、并行 bootstrap 各 slot、宿主级重启预算、心跳与按 pid 强杀；
  - bridge 恢复时投影历史（`initialHistory`、`history` / `tree` / `leaf`）；
  - 显示中断回合与 `TOOL_OUTCOME_UNKNOWN`；
  - 长会话并发争用做成回归场景。
- **Windows**（P0-4）：
  - shell 工具是 `pwsh` 不是 `bash`，UI、审批文案、提示词都要跟着改；
  - CI 验收必须带标准用户一路；
  - Q005 的预检与降级策略。
- **安全与隐私**（P0-2）：
  - 官方上报相关的行保持关闭并保留断言；
  - 宿主启动目录与 `$DSH_HOME` 下的 `.env` 会进工具环境，P1 要隔离；
  - pnpm 装插件写用户目录并访问网络，走白名单 + 预装。
- **权限**：决策 001 第 3 条的移植；建议把 `src/runtime/plugins/permissions/` 抽成纯库，DSH 插件和可能的 SDK 引擎共用。

## 没覆盖的

- 加密机全部项与官方 DSH Desktop 对照组（P2 前）。
- Windows 10 / 11 客户端、交互式登录、杀软 / AppLocker / 组策略、中文用户名与中文路径、数据盘工作区。
- macOS 全部。
- 真实模型下的行为质量：P0 全程只打本地假网关。
