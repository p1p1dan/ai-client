# P1-14 界面复点验（开发机，2026-10-18）

看板 Next Target 第 4 项「P1-14 其余」的第一条：在开发机上用开发版点决策 156 末尾的 11 项、P1-7e e6（决策 145）、P1-8 的小上限提示条与「继续」和退化回复的失败卡、P1-3e 三会话杀宿主。打包版首屏与权限页要在 Windows 测试包上看，不在本次范围。

## 环境与做法

- **机器与代码**：Windows 开发机；分支 `claude/claude-sdk-engine-mvp-162021` 的 `a16cf508`。
- **开发版**：用 `src/claude-sdk-host/tools/gui-probe.mjs` 起，隔离的临时 home，中文界面。
- **模型与引擎**：
  - 模型只用本机假网关 `fake-gateway.mjs --plan dsh-p0-2`。
  - 假网关的 OpenAI 协议只回文字，所以打开开发人员模式、关掉「Agent SDK 引擎」，让 Anthropic 协议的 `glm-anth-1` 走 DSH，档位是全自动。
- **为测试改的设置**：
  - 容量设成 3（`AICLIENT_PI_WORKER_CAPACITY=3`），用来触发容量回收；
  - P1-8 用 `dsh-home/cordis.patch.yml` 把轮次上限设成 3。
  - 做完都已还原。
- **怎么点**：经 CDP 在页面里派发事件，不是真的鼠标键盘，所以焦点框的观感没法判断。
- **关于窗口被挡住**：
  - 开发版窗口被别的窗口挡住时，Chromium 把页面当成隐藏，不再出动画帧，对话框停在打开动画的第一帧，焦点也落不进去。
  - `gui-probe.mjs` 为此加了 `CCSDK_GUI_KEEP_RENDERING=1`（带上 `--disable-backgrounding-occluded-windows` 等三个开关），本次后半程都在这个模式下做。
  - 前半程的检查与动画、焦点无关，结果不受影响。

### P1-3e 三会话杀宿主

- **做法**：三个会话同时在线，杀一次宿主：
  - 空闲：一个已结束的对话；
  - 流式：P0-PACED 60 秒；
  - 工具在跑：P1-CHAIN 让 pwsh 睡 60 秒。
- **流式会话**：正文停在中途，标「失败」，出现「对话引擎意外退出……各个对话会自动重新连上」失败卡，带「继续」。
- **工具在跑的会话**：出现「引擎意外停止，这一轮没有完成」注记与同样的失败卡；后台任务窗为空；没有留下睡眠的 pwsh 进程。尾行的问题见发现 2。
- **空闲会话**：自动重新连上，见发现 3。
- **宿主**：随即自动重启。
- **没做**：SIGSTOP 那一轮只在 Linux 上有意义，没做。

## 发现（没改，待定）

1. **带附件发送的占位显示不出来**：
   - 粘贴一张图片后发送，占位是「正在发送…」，不是「正在发送 1 个附件…」。
   - 原因：`ChatComposer.tsx` 在发送的提交点（T-19）就把附件草稿清空了，而占位读的是 `attachments.drafts.length`，发送中永远是 0。
   - 要显示，得改读这次发送快照里的附件数。
2. **跑过工具后才失败的回合，尾行仍写「完成于」**：
   - 防空转掐断的回合写「✻ 完成于 13:03 · 3 次工具调用」，可失败卡写的是「一个都没有执行」。
   - 宿主崩溃时工具正在跑的回合写「✻ 完成于 13:05 · 1 次工具调用」，就在「这一轮没有完成」注记下面。
   - 请求一个字未回的失败回合没有这个问题（第 11 项）。
   - 看起来是 `endedWithoutReply` 的判断没有覆盖「已经有工具步骤、随后失败」的回合。
3. **宿主重启后，空闲的失败对话「失败」徽标消失**：
   - 那个对话重新连上后，徽标没了，时间线的失败卡换成历史注记，失败信息还在。
   - 尾行只剩一个光秃秃的「✻」。
   - 重启应用后也是这样。
   - 要不要保留徽标、尾行该显示什么，待定。
4. **失败对话被容量回收后再点开，输入框里有那条已发出的消息原文**：
   - 同一次运行里出现；重启应用后输入框是空的。
   - 像是失败时把文字还给了输入框的草稿，回收后又读了出来；消息本身已经在时间线上。
5. **终端输入框的读屏标签是英文**：`aria-label="Terminal input"`，是 xterm 自带的，没走词条。
6. **「创建 worktree」对话框在界面上没有入口**：`CreateWorktreeDialog` 没有被任何组件渲染，`useComposerTarget` 准备的参数也没人用，没法点验。是要恢复入口还是删掉，待定。
7. **侧栏行之间没有方向键导航**：Tab 与 Enter 可用，方向键不移动。不是回退，记一笔。
