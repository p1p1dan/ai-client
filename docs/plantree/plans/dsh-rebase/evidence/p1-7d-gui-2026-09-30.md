## 问题清单（按严重程度）

**1 中：回退到用户提示后，提示没有回到输入框（A3）。**
- 现象：树对话框里对第二条用户提示点「回退到这里」→「回退」后，时间线正确地只剩第一回合，但输入框是空的。
- 复现：
  1. 新会话发两轮。
  2. 打开会话栏「会话分支」，对第二条 user 节点点回退并确认。
  3. 看输入框。
- 初步定位：
  - bridge 在 `src/dsh-host/bridge/forkSeed.ts:397-422` 为用户节点算出 `editorText`，`WorkerManager.ts:1947` 和 `src/preload/index.ts:1183` 也都透传了它；
  - 但 `src/renderer/components/chat/SessionTreeDialog.tsx` 的 `handleRewind` 只做 `resetSessionScopedRendererState` 和 `setSnapshot`，没有把 `result.editorText` 写回输入框；
  - 全渲染层没有任何地方读 `editorText`。

**2 中：新建的分叉打开时时间线为空，还显示英文空态（A4）。**
- 现象：分叉创建后自动切过去，时间线只有「No messages yet. Send a prompt to stream from the Agent Host.」。在里面发一轮，也只看得到新的这一轮。切走再切回不变。重启应用后重开，分叉点之前的回合才出现。模型上下文一直是对的（RECALL 结果正确）。
- 复现：
  1. 会话有两轮以上。
  2. 在树对话框里对第一条 assistant 节点点「从这里分叉」。
- 初步定位：
  - `src/renderer/stores/chatSessionActions.ts:165-233` 的 `materializeIndexedPiChatSession`（即 `materializeForkedChatSession`）把分叉以 host-bound、无消息、active 的状态放进 store；
  - 之后既没有请求历史页，也不走预览，所以 seed 的内容要等下次冷启动走 `readPage` 才出现。

**3 中低：会话状态一变，侧栏就把它顶到「最近」最前面，显示 now。**
- 现象：
  - 新建第 7 个对话时，容量回收（capacity 6）会把空闲会话标成 `disconnected`；
  - 宿主重启后，被 resume 的会话会收到 `idle`；
  - 这两种情况下，用户没碰过的会话都跳到「最近」顶部显示 now，用户正在用的会话反而被挤下去。
  - A2、B3、B7、A10 的截图里都能看到，例如 A2-after-host-kill 中 4 个无关会话排在当前会话上面。
- 初步定位：`src/renderer/stores/chatSessions.ts:644-659` 的 `upsertSessionStatus` 在每次状态写入时都执行 `updatedAt: Date.now()`，`settleFailedStatus` 同理。

**4 低：窗口重载后，正在跑的目标轮次没有补水（B4）。**
- 现象：
  - 重载后目标条显示「等待下一轮」，这一轮在时间线上显示「完成于 …」，但它的命令还在跑，最后一个 bash 调用仍未结算；
  - 同时，重载后应用落到一个新建的空「Live Agent Host」对话，而不是重载前的对话；早先那个「Live Agent Host」被改名成「Session srd2ne」；
  - 重载后前几秒，中栏只画了约 560 px 宽，右半边空白，随后恢复。
- 初步定位：
  - 目标条的「进行中 / 等待」取自渲染层会话状态（`sessionPanelsModel.ts` 的 `turnInFlight`），重载后会话状态回到 idle，只有 panels 补水了；
  - 活动会话的选择在 `ChatWorkspace.tsx:229-236` 与 `useSyncChatWorkspaceTree.ts` 的「Live Agent Host」兜底。
- 说明：dev 版才有 reload（`MenuBuilder.ts:94`），正式包用户碰不到，所以记为低。

**5 低：点「继续」后，目标条会闪一下「目标已挂起 · 重开会话、回退或打断后需要手动继续」（B2、B3）。**
- 现象：暂停后或受阻后点「继续」，trace 里有 0.4～1.2 s 处于 `suspended`，文案正好与用户刚做的操作相反。

**7 低：失败回合重开后的兜底句（A5，清单要求给判断）。**

  - 改成中文，并按通知或中断注记的样式画，例如「这一轮没有完成：模型服务返回了错误，没有保存任何回复。」；
