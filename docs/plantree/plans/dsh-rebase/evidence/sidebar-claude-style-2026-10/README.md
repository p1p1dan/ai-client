**状态：v6 定稿（2026-10-12；v5 于 10-11 认可），作为[决策 183](../../decisions/183-sidebar-claude-style-redesign.md) 的验收基准。**

`prototype.html` 单文件、离线可用，数据全部虚构。默认视图即定稿；工具条除主题（浅 / 深）外的开关（面板标题、搜索框、分隔线、账户栏）都是对比用，标「已定」的选项即定稿。文件里 `.vB` 那套样式（文件夹层级）是 v1 的对比项，已否决。

按用户要求，预览阶段只出效果、不截图、不跑判据；验证在开发阶段做。

## 迭代

- **v1**：去掉「正在活动」与板块标题，临时对话成为一个分组，顶部竖排导航 + 搜索行，行尾时间可隐藏；工具条三个待定项（分组名样式、临时对话位置、行尾时间）。
- **v2**：用户定「灰色标签 / 置顶 / 时间默认隐藏」；去掉空仓库的「＋ 新建对话」行。
- **v3**：分组小三角展开时也常显；未启动对话显示更淡的空心圈。
- **v4**：展开的小三角改回只在悬停时显示（用户：「好乱」）。
- **v5**：「全部折叠」改为开关（全部折叠后变「全部展开」）；加「『聊天』面板标题」对比开关，用户看后定为五个面板都去掉标题栏。实现期间又加了「搜索框：原型 / coss 默认」对比开关，用户选原型。
- **v6**（2026-10-12，用户在本机开发版上看过之后）：三个区界限不明显、账户栏像一行对话。加「分隔线」「账户栏」两个对比开关，用户定为「通栏细线」+「32px、不显示用量」。现在的默认视图即定稿。
