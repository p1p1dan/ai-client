# GUI / Windows / 加密机最小现场验收清单

Role: acceptance-procedure。本文件是可复用操作步骤，条目不表示当前未完成。实际结果只回填[核心任务树](../runtime-evolution/README.md#gui-任务树)并链接版本证据。现场 test.11/test.12 的 Windows 就是 TEC 加密机；既有结果见[现场报告](../../../../Windows-P4-6-evidence/test12-reverify.md)。
测试安装包须包含 A/B/C/D/E 与最终复查提交，不能仅凭 1.0.0-test.9 文件名判断；记录提交号、安装包来源、系统时间、操作系统和是否加密机。

## 1. 工作目录菜单与终端设置（问题 1、2）

- 左栏目录 hover 后单击“…”：松手菜单保持；单击设置/移除项打开对应界面；Esc 和外部点击关闭，焦点可回到触发器，之后页面没有遮罩阻塞。
- 设置 → 终端：进入不崩溃；切换 Shell、Custom 并填写参数、DOM/WebGL、回滚行数、主题/收藏；离开再进入不出现 #185。Windows 至少测 PowerShell/Custom。

## 2. 文件打开（问题 7）

- 关闭全部编辑器标签，分别点聊天 Markdown 文件链接与 Pi read/edit/write 行路径：实际文件在编辑页打开。
- 同文件已有标签时复用标签；相对路径、绝对路径、C:\ 路径、带空格路径和 :行号/#L行号 均正确；缺失文件有通知；不是只展开文件树。

## 3. 新会话与 TEMP（问题 4、10）

- 普通项目、worktree、已有 TEMP 各输入 /new：新会话无旧对话内容，首次发送/工具 pwd 仍为原 cwd，旧会话与旧文件不变。
- 未绑定且从未发送的会话 /new 保持未绑定；已有 scratch cwd 的会话 /new 沿用该 cwd。正在运行时 /new 提示先停止；另一后台会话运行不应误阻止当前空闲会话。
- 在五月命名 TEMP 里“新建会话”明确沿用原目录；“新建临时工作区”新建目录时间与机器当前时间一致，不改五月目录。新建过程中切换会话，完成后不得抢选或误绑新会话。

## 4. 长输出、重试与状态（问题 5、6，含追加 529/4xx）

- 在长输出末尾遇到 529/429 等可恢复错误：末尾及输入区可见重试次数、可用的等待信息；详情可展开。
- 成功继续输出并完成后：旧重试提示和红框消失，最终不是失败状态。向上阅读时重试/继续输出都不强制滚底。
- 重试耗尽时保留明确终止错误；停止后无“仍在重试”。切换会话及重载不串状态。
- 等待模型/输出/执行工具/原生权限/扩展问答分别显示真实状态，等待确认期间不会伪报“正在输出”。

## 5. 权限与问答（问题 3、8）

- 普通自动放行不再刷多行 Allowed；授权详情可展开；人工批准结果可查，待确认、拒绝、权限失败仍可见。
- QuestionCard 与扩展问答都测：长问题/长选项、窄窗口、多问题、单选/多选/自由输入。按钮不重叠，内容可滚动，底部操作可达。
- Tab/方向键/Enter/Space 正常；QuestionCard Ctrl/⌘+Enter 提交，中文输入法确认文字不误提交；提交中防重复；模拟 IPC 失败可重试；完成只读；Esc 正确关闭/折叠。

## 6. 当前对话审阅（问题 9，2026-09-10 替代聊天内 diff）

- 常规设置 → 聊天中的文件修改 → 显示审阅入口；关闭并重启后保持关闭，再开启后会话标题栏出现“审阅”。
- 点击审阅，创建 test.txt 为 pong，再追加 abc；同一文件两条记录，分别为 A/M，增删行与各次执行相符。
- 覆盖 Write 和 Edit 都显示真实前后差异；失败、拒绝与仍在运行的操作不列为成功修改。
- 重启恢复历史后记录不重复；外部修改当前文件不改变旧记录；切换对话不串记录，有更早历史时可继续加载。
- 打开记录对应文件、切回审阅、关闭/展开/调整宽度正常；切换不丢未保存的编辑器内容；1000px 窗口检查聊天及审阅完整。
- 旧历史明确“参数预览/仅写入内容”，超限或二进制明确提示；Bash 与外部编辑不声称已捕获。中栏保留工具结果和失败信息。

## 7. 上下文详情（追加问题 11）

- 位置仍在原百分比入口；hover 或键盘 focus 可看详情，窄窗口不出屏；切换会话后不残留旧数据。
- 已用/剩余相反口径标清；最近一次已结算请求与累计分开；缓存命中率与真实 input/cacheRead 一致，工具摘要只计当前轮。
- 压缩后占用未知或历史会话暂无上报时不伪造 0%；界面不把未计量的速度/推理 token/工具 token 当真实值。

## 8. 输出跟随（追加问题 12）

- 原本停在底部：连续长文本、大代码块和突然一大段输出均跟随，跳底按钮不反复闪现；输入框多行增高/缩小、调整窗口高度后仍贴底。
- 输出中真实上滚：保留阅读位置，随后增长不抢回；主动回到底部或点跳底恢复跟随；切换会话不继承另一会话的阅读偏移。
- 在实际 Windows/加密机显示环境观察快速输出是否仍闪烁、跳动或撕裂；记录硬件加速设置与复现内容。Linux 禁用 GPU 的 Electron fixture 不代替此项。

## 9. 软件更新提醒（问题 16）

2026-09-10 用户决定：依赖真实发布源的版本发现、下载与重启安装暂缓验证；恢复时按本节执行。

- Windows 安装版关闭自动下载，启动后仍检查新版本并提醒；仅使用已有发布源中的合法测试更新，不用 Actions artifact 冒充发布源。
- 点击提醒可下载；下载完成点击“稍后”，遮罩清除、聊天可用，右下角入口可再次打开；Esc 与关闭按钮也正常。
- 下载失败可查看错误并重试；设置页面与提醒显示同一状态；重挂载界面可恢复主进程已下载状态。
- 点击“立即重启”才请求立即安装；原自动更新开启时的退出安装策略保持。真实下载/重启安装须在可更新安装包上执行。
- Linux deb/rpm 设置页说明使用系统包管理器或新版安装包，不初始化不支持的 updater。
