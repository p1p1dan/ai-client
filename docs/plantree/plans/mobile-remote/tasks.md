### 第一版落地说明（2026-10-23）

- **运行中可读历史**：`WorkerManager.peekHistory` + `chat:peekHistory`，直接返回、不广播、不抢归属；没在运行的 DSH 对话走宿主的预览读，SDK 对话要先打开。
- **中转**：`relay/server.ts`、`relay/main.ts`，打包成一个 `pilab-relay.mjs`（`scripts/build-relay.mjs`）。登录口令换 30 天签名 cookie，登录限速；接入口令给 PiLab；只转发帧。HTTPS 现在要自己给证书，非本机地址用明文要加 `--allow-http`；自动申请 IP 证书没做。
- **网页端改法**：没有复用渲染层组件（另起 Vite 入口与垫片的工作量太大），而是中转自带一个不需要构建的小网页 `relay/web/`：时间线（Markdown、思考折叠、工具行）、发消息 / 插话 / 停止、权限卡、提问卡、计划审阅、新建对话、接管。附件、切模型和强度没做。
- **插件**：`plugins/remote-access/`，`core.mjs` 处理请求、`main.mjs` 管连接（Node 自带 WebSocket，断线 1～30 秒重连，口令错显示在插件页）。
- **测试**：`remoteAccess.e2e.test.ts` 用真中转、真插件进程和脚本客户端跑通登录、机器列表、打开对话（带已弹出的权限）、未接管被拒、接管、批准、发送、桌面拿回、手机离开自动交还。
- **没验证的**：真 PiLab 应用里跑插件、真手机浏览器打开网页（只在测试和单独的 Node 进程里跑过）。
