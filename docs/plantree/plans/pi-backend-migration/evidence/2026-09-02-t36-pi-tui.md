# T36 Pi TUI / PTY / CLI evidence — 2026-09-02

## Landed scope

- Added a dedicated Main-owned `PiTuiPtyController` and `piTui` IPC/preload contract; generic `SessionManager` rejects agent PTYs.
- Launches the worker artifact's absolute bundled Pi CLI path with the packaged pinned Node runtime on Windows, Linux, macOS arm64, and macOS x64.
- Starts a fresh Pi session in the active workspace/config: no `--session` or `--continue`, so GUI and TUI never write the same JSONL.
- Sends initial prompts through bracketed-paste PTY input rather than process argv.
- Serializes lifecycle operations, filters stale generations, buffers suspended output, limits live PTYs to two, and evicts the least-recently-used suspended PTY before admitting another.
- Added GUI/TUI presentation mode persistence, workspace switch/dispose behavior, unsupported-extension `Open TUI` action, auth-required recovery, and Pi TUI based task auto-execution completion.
- Removed active multi-agent picker/detector/installer/onboarding IPC, Hapi/Happy/Cloudflared sharing, remote Claude plugin operations, and legacy agent settings surfaces. Git installation remains a separate product prerequisite.
