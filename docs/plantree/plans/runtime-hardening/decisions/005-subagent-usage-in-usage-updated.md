# 决策 005：子代理花费并入 usage.updated 事件的独立字段

日期：2026-09-14。状态：已采纳（用户拍板，回答 Q007）。

## 决定

子代理消耗的 token 与成本随父 run 的 `usage.updated` 事件一起送到 Main 与渲染层，事件里新增独立字段（如 `delegated`）标出其中委派占比；不新开事件种类。

## 理由

- 改动最小：渲染层 piTurnRollup 注释本来就设想「同一总量，可说明委派占比」，一处读取即可显示。
- 单独事件会让 Main 与渲染层各多一套处理，且总量口径要两处对账。

## 影响

- T020 按此实现；会话总用量含子代理花费，面板可展示委派占比。
- 审计 subagent-data-03（子代理花费无消费者）由 T020 关闭；signoff SA15 在 T020 落地后回写。
