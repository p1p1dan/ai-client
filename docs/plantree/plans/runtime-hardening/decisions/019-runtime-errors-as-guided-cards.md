# 决策 019：运行时错误统一改成带标题与下一步的引导卡片

日期：2026-09-17 · 拍板人：用户 · 状态：已决 · 任务：T070（批次 F，上机后）

## 问题（结 Q017）

重试预算耗尽、会话超预算等运行时错误目前只表现为一块裸的等宽字体红色错误块：没有标题、没有「接下来该怎么办」的引导，也没有重试按钮（DEV-24、DEV-33 两处真机点验暴露出的判据问题）。这与「会话历史已损坏」等已有的、带标题带引导的历史错误卡不是同一套规格，体验不一致。该问题此前登记为待拍板的 [Q017](../open-questions.md)。

## 候选与取舍

- **候选 A（选定）**：统一改成一张卡片——标题 + 一句话说明原因 + 下一步操作（重试 / 新开会话 / 去设置），原始报错原文折叠进「详情」区。
- **候选 B**：只是最小补丁，在现有红色等宽块上方补一行标题、下方补一行下一步提示，不改整体呈现形态。
- **候选 C**：维持现状。

取舍：选候选 A，并把落地排进**批次 F（上机之后）**——这是一处纯渲染层改动，不影响能否通过上机验收的判据，不需要挤在 T033 上机之前处理；`T062` 已经落地的 `ModelMissingNotice`（模型缺失提示卡）本身就是「一张带按钮的卡片」，可以直接复用它的骨架，不用另起一套样式和交互。

## 决定

采用**候选 A**，排入批次 F 的 **T070**。

## 理由

- 纯渲染层改动，不影响上机判据能否通过，排到批次 F 不拖慢现场验收。
- `T062` 的 `ModelMissingNotice` 已经是一张带标题、带按钮的卡片，骨架可直接复用，改造成本低。

## 后果与备注

- 至少要覆盖两类错误：重试预算耗尽、会话超预算。
- 原始报错文字保留（折叠进「详情」），不丢失排障信息。
- 中文界面下卡片本身的标题、原因、按钮文案必须是中文；只有折叠详情里的原始报错允许是引擎给的英文原文。
