# 决策 038：委派两层、思考预览与完成后折叠

日期：2026-09-23。来源：用户条目 a，并明确授权修改代码。

## 规则

1. 合并委派工具标题与子 agent 标题：`已委派 explore 执行 xxxx → 操作列表`，操作默认折叠，一次点击可达。保留子任务状态、失败、截断提示和输入/结果查看入口。
2. 思考正文先在展示层删除所有空白行（含仅空格/制表符的行），不修改原始数据，保留非空行缩进。按处理后的正文展示前 200 个 Unicode 码点；不超过阈值直接完整显示。超过后在正文末尾内联「展开」按钮，展开后变成「收起」；思考标题与尾部按钮共用全文/预览切换，收起仅回到预览，不隐藏整段思考。完整展示取消思考正文的内部限高滚动，展开/收起只改变当前思考内容，保留阅读位置；该次布局变化不触发跳到底部。后续流式追加沿用此前跟随状态，用户上滚时暂停跟随，不抢键盘焦点。
3. 外层过程组运行中默认展开。回合结束后使用完成阶段的独立展开选择，默认收起；用户仍可重新展开。未应答授权优先保持可达。
4. 即使只有一项过程，结束后也提供折叠头，避免单段思考残留在最终回答上方。运行中单项仍沿用 T112 直出。时钟归属与实际折叠头使用相同判据，防止重复计时行。
5. 沿用决策 033 D1 的完成时终稿提取规则；最终回答在折叠组外，错误/通知保留既有独立显示边界。

## 替代关系

- 替代决策 033 D2 的「结束后仍默认展开」。
- 替代决策 033 D3 的思考正文限高滚动，改为 200 字预览与页面全文流。
- 收窄 T112 的单项直出例外：仅运行阶段直出，完成阶段可折叠。
- 子 agent 的事件协议、活动缓冲区和运行生命周期不变；仅合并渲染入口。
