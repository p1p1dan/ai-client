# 决策 044：单条过程段也折叠，与多条保持统一

日期：2026-09-24。来源：用户待办 T11（「单条调用也折叠成『已执行』」），用户当日拍板「单条也折叠，保持统一」。落地任务 **T137**。推翻 T112（`f47a69b7`）。

## 背景

- T112 按用户 2026-09-21 现场意见「只有一条就直接显示，多条合并为 N 个步骤」落地：外层过程组恰好 1 项时不渲染折叠头，直接就地渲染该项（`turnProcessFold.ts` 的 `turnProcessGroupFolds`，步骤数 > 1 才折叠）。
- 结果是同一条时间线里有的过程段带折叠头、有的不带，形制不统一。

## 规则

1. 外层过程组不论几项，一律渲染折叠头，折叠头只报步骤数（含「1 个步骤」，恢复 T112 退役的单数词条）。
2. 默认开合沿用决策 038 规则 3 与决策 043：运行中展开、已结束收起；被插话或 Stop 打断的回合默认展开。
3. 强制展开不变：有未应答授权的回合（`turnWorkGroupAwaitsUser`）仍强制展开，单项组同样适用。
4. 工具行层面（`deriveToolGroupRows` 恰好 1 条不聚合）不变：单条工具行本身可点开看详情，已经是折叠态。

## 替代关系

- 推翻 T112 的「单条直出」。T113（回合信息钉末尾）、T114（悬停条只留复制）不受影响。
