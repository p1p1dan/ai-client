## 与 roadmap 字面不同的做法（已认可）

- T001：auto 档放行加 `!unresolvedPaths` 条件而非整行下移，避免顺带改动 scope / grants 语义；here-string 字面量登记为路径，会对 `cat <<< .env` 误拦一次（保守取舍）。
- T003：CLI 行不计入 seq 空间，同时对老文件保留「不超过此前 CLI 行数」的兼容额度；紧跟 CLI 行后一行豁免一次 lane 链校验；`assertHostPromptAllowed` 按会话键判断而非无参（无参会误伤切会话发送）。
- T004：`timed_out` 由 drain 兜底路径驱动，run() 自身返回 timed_out 的窗口极窄；顺带让 `subagents.projectInstructions` 选项真正生效。
- T005：compaction 的 latestUser 排除内部消息（契约 §3 明写，roadmap 未列）；golden 录制新增独立文件而非重录原文件。
- T002：`trustedPath` 让已信任技能目录默认 allow，任何层级的 `skill: ask` 都不弹卡，只有显式 deny 能拦；skill 进 plan 模式白名单。
- T007：`no_api_key` 只对需要 key 的 7 种协议且无 Authorization 类头时生效（bedrock / vertex / pi-messages 不受影响）。
- T008：「四个 RPC」实际只有三个带 targetPiSessionId；discard 传完整路径。
- T010：错误码集合含 EPERM / EISDIR / ELOOP，与 skills / mcp / prompt 三处一致。
