# T067 — i18n 补漏包（D9 / D20 / D21 / D26），批次 D4 / low

分支 `feat/runtime-evolution`，基线 HEAD `b3d751e3`。**未提交**。

一句话：这四条缺陷的共同点不是措辞不好，而是这些界面**根本没问过词典**。
所以修法统一成一件事——把固定文案变成词典键，在渲染处过 `t()`，带数值的用
`{{占位符}}`，不拼字符串。

仓库的 i18n 机制：`src/shared/i18n.ts` 是唯一词典，**英文就是键**
（`getTranslation` 在 en 下原样返回键），所以"英文词典同步"= 键本身即英文，
无需第二份文件；`englishTranslate` 是所有纯模块 `t` 参数的默认值，未接线的
调用点产出与改动前逐字节相同。
