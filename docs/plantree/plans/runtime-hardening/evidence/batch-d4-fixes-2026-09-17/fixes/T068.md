## 三、D23 — 两张卡的标题字重：`font-medium`(500) → `font-semibold`(600)

依据 `docs/design-system.md` §Font Weight：卡片 / 对话框 / 段落标题 = `font-semibold`（全平台可靠），
描述 / 占位文本 = `font-normal`；硬约束「500 不得作为任何层级区分的唯一载体」——Win10 的 Segoe UI 静态族
（300/350/400/600/700）没有 500，CSS Fonts 4 §5.2 规定**降到 400**，于是标题与正文逐像素相同。

只动 `QuestionCard.tsx`（两张卡同文件），5 处，无共用基类被改：

| # | 位置 | 原 | 现 | 对应审计行 |
|---|---|---|---|---|
| 1 | `QaHead` 段头（问答卡的「Questions」） | `font-medium tracking-[0.01em]` | `font-semibold tracking-[0.01em]` | token-audit「header `Questions` 14px/500 ⚠️」 |
| 2 | 问答卡问题正文（卡内标题） | `text-ui font-medium leading-relaxed` | `text-ui font-semibold leading-relaxed` | 「question text 14px/500 ⚠️」 |
| 3 | 权限卡段头（「权限」） | `font-medium tracking-[0.01em] text-foreground` | `font-semibold …` | 「「权限」label 14px/500 ⚠️」 |
| 4 | 权限卡标题行（「write — 写入工作区文件」） | `text-ui font-medium leading-relaxed` | `text-ui font-semibold leading-relaxed` | 「card title 14px/500 ⚠️」 |
| 5 | 选项**描述** | 继承 `Button` 基类的 `font-medium`（13px/500） | 显式 `font-normal` | 「option description 13px/500 ⚠️」 |

**刻意没改**：选项**标题**（`role="radio"` 按钮本身）保留基类 500 —— 分档表把 `button / label / 导航项`
判给 `font-medium`，它不是标题层级；`tracking-[0.01em]` 用在段头上（分档表段头档是 +0.04em）属另一条轻微偏差，
不在 D23 范围，未动；两处 10px（权限卡 `p-2.5`、选项行 `gap-2.5`）同理未动。
