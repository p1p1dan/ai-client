环境：run 2，pi-agent/models.json+auth.json 临时只留 probe-fake（假网关），两条 ai-client 会话各开一个 pi TUI。

## 观察序列
1) 聊天 A（session-1789666361268-er5utwj）点 TUI → pi 正常出屏（T065-A-first-open.txt，非空行 > 0）
2) 切到聊天 B（session-1789666291721-kopqqgu）→ 显示 Start Pi TUI → 点开 → pi 正常出屏（T065-B-first-open.txt）
3) 切回聊天 A → **整屏空白**：.xterm-rows 有 35 行，textContent 去空白后长度 = 0（T065-A-back-from-B.txt / T065-01-back-to-A.png）
4) 手动 window.electronAPI.piTui.resize(<A 的 terminalId>, 70, 20) → **整屏立刻恢复**（T065-A-after-manual-resize.txt）
5) 再切到聊天 B → 同样整屏空白（T065-B-back-from-A.txt / T065-02-back-to-B.png）

完整事件见 T065-tui-events.txt。
