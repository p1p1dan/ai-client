## 编排者补正

两处执行代理自报或遗留的问题，由编排者当场修掉：

1. **T075 的判空谓词把恢复态会话误判为全新**。`isFreshEmptySession` 原本只查 `hostBoundSessionIds`，而从磁盘恢复、转录尚未回放进内存的会话同样是零消息、`idle`、占位符标题——裸查会把一段真实对话判成「全新」，`retarget` 分支随即原地改写它的工作区绑定。改用 `computeEverHostBound`（额外认 `runtimeIdentity`），补回归用例并反向验证：只有新用例判红，其余 15 条不受影响。
2. **T075 漏掉一个入口，并留下三条静态测试失败**。临时对话分组右键菜单的「新建临时对话」被执行代理有意跳过（理由是「用户只点名了按钮和加号」），但那等于留了一个口子照样能堆空会话，已一并接入。`unboundChatEntryStatic.test.ts` 两条是代理改名后未跑到的遗留失败、`sidebarSectionMenus.test.ts` 一条由本次补接线产生，三条均改为钉住新函数名。

另有一条执行代理自查出的假断言值得记：`chatTimelineLayout.test.ts` 原用 `/text-[\w-]+/` 取首个 `text-*` 当颜色，但 header 的 class 是 `text-meta text-muted-foreground`，首个匹配到的是**字号**，导致三档塌成两档时该断言仍为绿。已改写为三条包含式断言并重新判红。

**本轮全程只有静态验证（类型、lint、单测），没有启动过 Electron。** 以下三处是算出来或推断出来的，不是看出来的，建议并入 T033 上机日：

1. **暗色第二跳对比度 1.33×**（工作组 header `text-muted-foreground` 6.70 → 思考/终端 `text-tool-arg` 5.02）。三档数值按 `globals.css` 的 oklch 值经 oklab → 线性 sRGB → WCAG 相对亮度换算得到；算法的自校验点是中间档算出的 7.20 / 6.70 与 `chatTimelineLayout.ts` 里 F456 批次自己记录的那对数字逐位吻合。够不够看需真机判定。若不够，可选项是把 header 抬到 `text-foreground`（两档差 2.27×）或调 `--tool-arg` 的混合比，两者都需要拍板。

3. **折叠后聊天区的整体清爽度**是否达到用户诉求，只有真机能判。
