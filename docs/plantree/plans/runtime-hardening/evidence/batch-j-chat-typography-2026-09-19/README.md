### 二、阅读栏字数实测

施工清单点名的一条待测：**正文 16px 下一行实际能装多少个中文字**，与 `--container-reading: 45rem` 按 15px 设计时的 48 字目标差多少。

取证要求：在真实窗口里量（量文字块的实际可用宽度，或直接数一行满行中文字数），不要用字号算术反推——`45rem` 是外部约束，换行位置受字距、标点、内边距影响，算术推出来的数字不算实测。记录四项：

- 窗口宽度、聊天区可用宽度、`--container-reading` 当前生效值；
- 16px（默认档）下一行中文字数；
- 提到 24px（上限档）下一行中文字数；
- 与 48 字目标的差值，以及是否仍在可接受区间。

**决策 032 已明确本轮不动 `--container-reading`**，所以本项是**登记现状**而不是判据：量出来偏窄也算通过，只是把代价写清楚。预期文件名 `reading-column-measure.txt`，附量法说明。
