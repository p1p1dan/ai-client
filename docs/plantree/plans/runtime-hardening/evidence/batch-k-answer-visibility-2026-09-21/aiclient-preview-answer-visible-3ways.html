三栏的差别，用一句话说
  • A 的问题是内容没了——正文和工具混在一层里，读者要展开折叠头去找模型说过的话。这是你报的那条。
  • B 和 C 正文都是 4 段全露，区别只在工具行：3 行 vs 8 行。工具行越少，读者从提问走到答案的路径越短（这正是 2026-09-19 那次拍板要的效果）；
  • C 是 2026-09-18 那次报告「各种调用授权穿插在 agent 输出中，严重影响观感」的形态。把 B 栏的开关拨到「展开」，你会看到 B 展开之后就退化成 C，只是多了一行计数。
  • 折中点是「段」的粒度：B 用「一段连续的工具调用 = 一行」，所以屏幕上过程行数 ≈ 正文段数。工具跑得越多，B 相对 C 的优势越大——真实回合里工具常常是几十次，不是这里的 8 次。
