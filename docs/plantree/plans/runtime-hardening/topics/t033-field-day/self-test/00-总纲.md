Role: detail shard。上位：[T033 上机日执行单](../../t033-field-day-runbook.md)。判据权威：[checklist-e.md](../../../checklist-e.md)。建立：2026-09-17。

## 1. 这份文件是干什么的

原来的执行单假设「现场一个人 + 开发机一个编排器」实时一问一答。这一版不是：**你一个人，按清单从头做到尾，中间不需要问任何人**；全部做完之后，把证据目录打包 + 结果表一起交回，由编排器统一判读。

所以每一项都写成了四段：**准备 → 操作 → 看什么 → 记录**。「看什么」里同时写了「通过长什么样」和「不通过长什么样」，你不需要理解背后的设计也能判。

**你不需要做的事**：判断某一项的结论意味着什么、决定要不要改代码、回填任何计划文档。这些是编排器的事。你只要把「实际看到的现象」如实记下来。

---

## 2. 四个档位

每一项标题后面有一个方括号标记，意思是：

| 标记 | 含义 | 时间不够时 |
|---|---|---|
| 【必】 | 执行单 §7「第一刀」：不做就不能签收 | **不能砍** |
| 【绿】 | 第二刀：做了能让某个计划节点转绿 | 第二优先 |
| 【探】 | 第三刀：纯探索，做完至少能回答「有没有」 | 第一个砍 |
| 【不做】 | 已结案 / 已退役 / 已裁决不需人工执行 | 直接记 🚫，不展开 |

> 档位的来源：执行单 §6 的「34 条必做」映射表 + §7 的三刀。执行单没有点名的项，按「它挂在哪个回填出口」归档——挂在 P4-6 / P6-3 / 旧树节点等回填出口的记【绿】，只是确认性的、且现场构造条件很苛刻的记【探】。有异议的地方留给编排器复判，你照标记做即可。

---

## 3. 结果只有三种

| 记号 | 什么时候用 | 附加要求 |
|---|---|---|
| ✅ | 现象与判据相符 | 必须挂证据文件 |
| ⛔ | 现象与判据不符，或做不下去 | 必须挂证据文件 **+ 一句实际现象** |
| 🚫 | 这一项没做 | 必须写明原因（时间不够 / 前提缺失 / 已裁决不做） |

**不接受只写「通过」。** 「看着是对的」这句话在证据里不成立。

⛔ 的那一句要写**你看到的东西**，不要写你的推测。对照：

- 好：「工具行报 `io_tsd_unavailable`，文案里 fallback 写的是 disabled」
- 差：「TSD 好像没生效」

## 4. 第 0 步：开工前必须做完的七件事

这一节做不完，后面会整组卡住。预计 30～40 分钟。

### 0.1 填一个变量：安装目录

打开 PowerShell（普通权限），先确认应用装在哪：

```powershell
Test-Path (Join-Path $env:LOCALAPPDATA 'Programs\AiClient\AiClient.exe')
```

返回 `True` 就用默认位置，什么都不用改。返回 `False` 说明装的时候改过目录（安装包允许改），自己找到那个目录，后面所有命令里的 `$app` 都用它：

```powershell
# 下面这一行按实际情况改，之后整天都用这个变量
$app = Join-Path $env:LOCALAPPDATA 'Programs\AiClient'
Get-ChildItem $app | Select-Object -First 5
```

顺手确认随包 Node 在：

```powershell
& "$app\resources\node-runtime\node.exe" -v      # 期望 v24.18.0
```

### 0.2 核三个安装包的哈希

新旧两版的 `package.json` 都是 `1.0.0-test.13`，**安装包文件名一模一样**，只有哈希能分辨。动包之前先对一遍：

```powershell
Get-FileHash -Algorithm SHA256 'C:\t033\pkg\new-13e6cdb7\AiClient Setup 1.0.0-test.13.exe'      | Format-List Hash
Get-FileHash -Algorithm SHA256 'C:\t033\pkg\new-13e6cdb7\AiClient-1.0.0-test.13-portable.exe'   | Format-List Hash
Get-FileHash -Algorithm SHA256 'C:\t033\pkg\prev-c0ae2a34\AiClient Setup 1.0.0-test.13.exe'     | Format-List Hash
```

对照（只看前 8 位即可）：

| 文件 | 来自 | SHA256 前 8 位 |
|---|---|---|
| `new-13e6cdb7\AiClient Setup 1.0.0-test.13.exe` | run 35295618831 installer（**已安装的就是这个**） | `b0ce16cb` |
| `new-13e6cdb7\AiClient-1.0.0-test.13-portable.exe` | run 35295618831 portable | `431cb7ed` |
| `prev-c0ae2a34\AiClient Setup 1.0.0-test.13.exe` | run 34424337205 installer（上一版，PKG-22 用） | `ee9a1387` |

对不上就停下来，在结果表里记一行 ⛔ 并写清楚实际哈希——后面所有「这一屏是哪个包开出来的」都靠它。

把三行输出存成 `C:\t033\evidence\baseline\baseline-00-package-hashes.txt`。

### 0.3 环境自检

整段复制粘贴执行，把输出**整段**存成 `C:\t033\evidence\baseline\baseline-01-environment.txt`：

```powershell
'=== OS ==='
(Get-CimInstance Win32_OperatingSystem) | Select-Object Caption, Version, BuildNumber, OSArchitecture | Format-List
'=== 工具在不在 ==='
foreach ($t in 'bash','pwsh','git','node','gh','procmon','procmon64') {

}
'=== Git 安装目录（WIN-16/17/29 要临时移走它）==='
Get-ChildItem 'C:\Program Files\Git','C:\Program Files (x86)\Git', (Join-Path $env:LOCALAPPDATA 'Programs\Git') -ErrorAction SilentlyContinue | Select-Object FullName
'=== 随包 Node ==='
& "$app\resources\node-runtime\node.exe" -v
'=== 数据目录 ==='
'userData    : ' + (Join-Path $env:APPDATA 'jyw-ai-client')
'状态根      : ' + (Join-Path $env:USERPROFILE '.pilab\jyw-ai-client')
'日志目录    : ' + (Join-Path $env:APPDATA 'jyw-ai-client\logs')
'临时工作区根: ' + (Join-Path $env:USERPROFILE 'JYWAI\temporary\unbound-sessions')
'=== 磁盘 ==='
Get-PSDrive -PSProvider FileSystem | Select-Object Name, @{n='FreeGB';e={[math]::Round($_.Free/1GB,1)}}
```

还要**手工**补三条写进同一个文件（命令查不到，只能你自己填）：

1. **受加密策略的目录是哪一个**（绝对路径）。ENC 组每一项都在里面做。
2. **Process Monitor 有没有**（Sysinternals 的 `Procmon.exe`）。ENC-15 / ENC-24 要用它。没有就把这两项记 🚫。
3. **你配的 provider 名与模型名**（例如「自建网关 + claude-sonnet-5」）。**不要写任何密钥，不要贴 vault.json 的内容。**

样本包在仓库的 `docs/plantree/plans/runtime-hardening/evidence/batch-e-devbox-2026-09-17/tools/field-samples/`，整个目录拷到 `C:\t033\field-samples`，然后：

### 0.6 关掉应用，带 trace 变量重新启动

**这是整份自测最容易忘、忘了就白做的一条。** 没有这个环境变量，runtime 的执行轨迹（trace）只留在内存里、不落盘，所有「抓 trace 的某某行」的判据都取不到证。

```powershell
Stop-AiClient
Start-AiClient
```

`Start-AiClient` 做的就是先设 `AICLIENT_RUNTIME_TRACE_DIR=C:\t033\trace` 再启动。等价的手打写法：

```powershell
$env:AICLIENT_RUNTIME_TRACE_DIR = 'C:\t033\trace'
& "$app\AiClient.exe"
```

跑一条随便什么消息之后确认 trace 真的落盘了：

```powershell
Get-ChildItem C:\t033\trace
```

看到 `runs.jsonl` 才算成功。

> 顺带一条纪律：安装版和 portable 版**共用同一份用户数据**，而且应用有单实例锁，**不能同时开两个**。要换一个版本跑，先 `Stop-AiClient`。

## 5. 通用规矩

### 5.1 每次启动都带 trace 变量

用 `Start-AiClient`。如果某一项要求你先改环境变量再起应用（例如 ENC-23 要加一个变量），那一项会写明，做完再按它的「恢复」步骤改回来。

trace 是**累加**的：`runs.jsonl` 会一直往后写，超过 8 MiB 才轮转成 `runs.1.jsonl`。所以「找刚才那一次」要用 `Get-Trace -Pattern ... -Tail 3` 取最后几条，或者看时间戳。

### 5.2 证据放哪、叫什么

```
C:\t033\evidence\
├── baseline\     第 0 步的产物
├── enc\          ENC 组
├── win\          WIN 组
├── pkg\          PKG 组
├── model\        MODEL 组
└── d4\           批次 D4 复验
```

命名：**`<组>-<两位编号>-<英文短横线 slug>.<扩展名>`**，例如 `enc-16-read-plaintext.png`、`enc-07-sha256.txt`。编号不足两位补零（`enc-07`，不是 `enc-7`）。

每一项的「记录」段已经把文件名写好了，照抄就行。

### 5.3 怎么截图

`Win+Shift+S` 框选 → 复制到剪贴板 → 用「画图」或「截图工具」另存为，存到「记录」段指定的路径与文件名。一屏能说明问题就截一屏，需要展开工具行 / 权限卡才看得清的，先展开再截。

文本类证据可以用辅助函数直接落盘，不用手打路径：

```powershell
Get-Head16 -Path $file | Save-Evidence -Group enc -Id 17 -Slug header-bytes
```

### 5.4 碰到与判据不符的现象，多抓这四样

现场机器当天之后就没了，**宁可多抓**。看到任何意外现象，立刻补这四份：

1. **进程树**：`Get-AiClientTree | Save-Evidence -Group enc -Id <编号> -Slug process-tree`
2. **trace 尾 50 行**：`Get-Trace -Pattern . -Tail 50 | Save-Evidence -Group enc -Id <编号> -Slug trace-tail`
3. **应用日志尾 200 行**（路径见下）
4. **一张截图**，把出错的那一屏整屏截下来

应用日志（打包态，源码 `src/main/utils/logger.ts:87-94` + Electron 的 `logs` 路径约定）：

```powershell
$logDir = Join-Path $env:APPDATA 'jyw-ai-client\logs'
Get-ChildItem $logDir | Sort-Object LastWriteTime | Select-Object Name, Length, LastWriteTime
Get-Content (Join-Path $logDir ('aiclient-{0}.log' -f (Get-Date -Format 'yyyy-MM-dd'))) -Tail 200
```

同目录下还有一个 `main.log`（electron-log 的默认文件名）——检查单里提到的 "main.log" 指的就是它，两个文件**并存**，两个都看一眼。

> 注意：日志级别的地板是 `info`，也就是说即便设置页把日志开关关掉，`info` 及以上仍然会写进去。所以「日志里什么都没有」不太可能是「日志被关了」，更可能是真的没发生。

### 5.5 需要临时改机器状态的项

凡是要改注册表、改目录名、改权限、加环境变量、写假锁文件的项，**恢复步骤写在同一项的最后**。做完一项立刻恢复，不要攒到最后——攒到最后会忘，下一项的结论就全错了。

## 7. 辅助脚本用法速查

载入：

```powershell
. C:\t033\t033-helper.ps1
```

| 函数 | 干什么 | 典型用法 |
|---|---|---|
| `Start-AiClient` | 设好 trace 环境变量再启动应用 | `Start-AiClient`／`Start-AiClient -App 'D:\AiClient-old'` |
| `Stop-AiClient` | 请应用自己关闭，等 5 秒，再报告残留进程 | `Stop-AiClient` |
| `Snap-Baseline` | 进程列表 + 三个目录清单 + 会话索引副本，落到 `evidence\baseline\` | `Snap-Baseline -Tag before -PolicyDir 'D:\Enc\t033'` |
| `Get-Trace` | 在 `runs*.jsonl` 里找行，自动跳过 `runs.rotate.lock` | `Get-Trace -Pattern 'io_tsd_unavailable'`／`Get-Trace -Pattern . -Tail 50` |
| `Get-Head16` | 读文件头 16 字节，给十六进制 + ASCII，并判 TSD 容器头 | `Get-Head16 -Path 'D:\Enc\t033\tracked.txt'` |
| `Get-AiClientTree` | AiClient 及全部子孙进程，列 Name/PID/PPID/CommandLine | `Get-AiClientTree \| Format-Table -AutoSize` |
| `Save-Evidence` | 按命名规矩写 txt | `Get-AiClientTree \| Save-Evidence -Group enc -Id 1 -Slug tree` |

`Get-Head16` 的两个关键字段：

- `IsTsdMagic` —— 前 16 字节是不是 `%TSD-Header-###%`
- `IsContainerSize` —— 文件大小是不是 ≥ 4096 且为 4096 的整数倍

**两个都为 True，产品代码才把这个文件当加密容器**（源码 `src/runtime/host/io.ts:152-155`）。只满足一个的情况在 ENC-21 里会专门用到，别把它读成「加密了」。

任何一个函数都能查帮助：`Get-Help Get-Head16 -Full`。

## 8. 做完怎么交回

### 8.1 打包证据目录

```powershell
Compress-Archive -Path C:\t033\evidence -DestinationPath C:\t033\t033-evidence-2026-09-17.zip -Force
Get-Item C:\t033\t033-evidence-2026-09-17.zip | Select-Object FullName, Length
```

（日期用你**实际做自测的那一天**，不是这份文件的日期。）

### 8.2 把结果表贴回来

每个分片文件末尾都有一张空的「结果表」。把它**整张复制出来、填好、和 zip 一起交回**。四列都要填：

```
| 编号 | 结果 | 一句现象 | 证据文件 |
```

- **编号**：照抄，不要改
- **结果**：✅ / ⛔ / 🚫 三选一
- **一句现象**：⛔ 必填，写你看到的东西；✅ 也建议写一句（例如「读到明文，哨兵串完整」）
- **证据文件**：文件名即可，不用写全路径

### 8.3 交回时顺带说三句

1. 今天一共做了几项、砍了几项（砍的原因）
2. 有没有哪一项**做到一半做不下去**（比 ⛔ 更糟的情况，说明清单本身漏了前提）
3. 有没有你觉得「不对劲但判据没问」的现象——这条最值钱，机器当天之后就没了
