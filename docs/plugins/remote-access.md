# 手机远程：部署与使用

在手机（或任何浏览器）上接着用各台机器上的 PiLab 对话。三样东西：

| 东西 | 放在哪 | 文件 |
|---|---|---|
| 中转服务器 | 一台手机能访问到的服务器（有公网 IP 的，或者就在本机） | `pilab-relay.mjs` |
| 「手机远程」插件 | 每台要被远程使用的 PiLab | `pilab.remote-access-<版本>.pilabplug` |
| 网页 | 不用装，中转服务器自带 | 打开中转的地址即可 |

## 1. 启动中转服务器

需要 Node 20 或更新版本。

```bash
# 公网服务器，先用明文 HTTP 试（口令和对话会以明文经过网络，只建议测试或内网用）
node pilab-relay.mjs --port 8790 --allow-http

# 公网服务器，有证书时
node pilab-relay.mjs --port 8790 --tls-cert cert.pem --tls-key key.pem

# 只在本机用
node pilab-relay.mjs --host 127.0.0.1 --port 8790
```

启动后会打印：
- **手机打开的地址**，如 `http://203.0.113.7:8790`
- **登录口令**：手机上登录用
- **接入口令**：填进每台 PiLab 的插件设置

口令存在 `~/.pilab-relay/relay.json`（`--data` 可以换目录），下次启动沿用。删掉这个文件再启动会生成新口令。

要一直运行，可以用 `nohup`、`pm2` 或 systemd。服务器防火墙要放行这个端口。

## 2. 在 PiLab 里装插件

1. 设置 → 插件 → 「从文件安装…」，选 `pilab.remote-access-<版本>.pilabplug`。
2. 展开「手机远程」，填：
   - **中转地址**：`203.0.113.7:8790`（用了 HTTPS 写 `https://...`；本机测试写 `127.0.0.1:8790`）
   - **接入口令**：中转打印的接入口令
   - **这台机器的名字**：手机上看到的名字，不填用主机名
3. 打开开关，确认权限。状态行变成「已连上中转」就好了。

每台要远程用的机器都这样装一次，填同一个中转。

## 3. 在手机上用

1. 浏览器打开中转地址，输入登录口令（30 天内不用再输）。
2. 看到所有连着的机器，点进去是这台机器的对话，按文件夹分组；右上角「+」在已有的文件夹里开新对话。
3. 打开一个对话：
   - 电脑上正在用时，底部显示「正在 桌面 上使用，这里只能看进度」，点 **接管** 才能发消息、批准、回答提问。
   - 接管后电脑那边变成只读，显示「正在 网页 · iPhone 上使用」，电脑点「接管」就拿回来。
   - **停止**两边都能按。
   - 对话没在运行时会显示「这个对话还没打开」，点「打开」。

## 说明与限制（第一版）

- 中转只转发，不存对话；谁有登录口令就能操作所有连着的机器，口令保管好，公网请尽量用 HTTPS。
- 网页端支持：看历史与实时进度、发消息（运行中发的是插话）、停止、批准权限、回答提问、计划审阅、新建对话、接管。不支持附件、切模型和强度、文件与终端。
- 不用域名的自动 HTTPS（自动申请 IP 证书）还没做，现在要自己给证书或用 `--allow-http`。
