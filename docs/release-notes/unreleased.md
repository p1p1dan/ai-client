# PiLab Ai 1.2.0

## 新功能

- **内核优化升级。** Claude 模型调用更稳定，在加密等环境下调用工具更可靠，输出效率更高。
- **工具能力增强。** 其余模型新增网页抓取，文件搜索更强，联网检索能力增强。
- **运行中的操作。** 回复进行中按回车即可插话；停止只停当前回复，后台运行的任务继续；
  新增「转到后台」。
- **停止或失败时写明原因。** 输出保持展开，末尾说明原因。
- **全自动模式少打扰。** 只在删除等危险操作、以及操作工作区以外的文件时询问。

## 问题修复

- 更新时不再下载两次。
- Claude 对话闲置一段时间后再发送，之前的回复不再消失。
- 多个对话同时运行时，新对话的消息不再卡在排队。
- Windows 上停止回复不再卡住。
