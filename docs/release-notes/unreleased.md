# PiLab Ai 1.2.3

## 新功能

- **对话区有两种显示方式。** 在「设置 → 外观 → 聊天区 → 对话显示方式」里切换，默认是终端式。
  终端式照命令行的样子一步一行，命令下面显示输出的开头几行，思考显示在它发生的位置；
  桌面式把一段工作折成一行，点开再看每一步，正常跑完的命令不显示输出，失败的只写原因。
- **运行中的状态只显示一处。** 回合进行中，计时和「esc 中断」挂在正在思考或正在跑的那一行上，
  底部不再另起一行重复说明。
- **子代理在对话里只占一行。** 运行中写它正在做的那一步和一共调用了几次，结束后写调用次数、用量和用时；
  点这一行打开子代理自己的对话，不再在对话里展开一长串步骤。

## 问题修复

- **自动更新不再停在旧版本。** 之前的版本下好一个更新后就不再检查，直到退出应用，期间发布的新版本
  要先装上旧的、再更新一次才能拿到。现在下好以后照常检查，有更新的版本就换成新版本
  （自动更新关着时只提示），退出时只安装最新的那个。
- 点「立即重启」时先检查一次更新，最多等 10 秒；发现更新的版本就不装旧的。
- 更新下载 5 分钟没有进展会自动停止，提示「更新失败」，可以点「重试」。
- 右下角的更新提示可以关掉，下次启动再提醒；更新已就绪时，设置页的「检查更新」也能点。
