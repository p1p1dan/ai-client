# PiLab Ai 1.2.2

## 新功能

- **会话侧栏新增「产出」卡。** 本次对话新建的文档、网页、图片、表格、演示稿列在这里，最新的在上面；
  网页在预览窗口打开，其余在编辑器里打开，右键可复制路径、在资源管理器中显示。
- **旁问改成独立窗口。** 可以拖到主窗口外面、放到另一块屏幕上，位置会记住；跟主窗口一起最小化，
  不在任务栏单独占一项。也可以停靠在对话右边。切到别的对话时，旁问留在原来的对话，标题写明读的是哪个。
- **会话侧栏和右侧卡片可以同时打开。** 窗口变窄时依次让位：侧栏变窄、两列卡片叠成一列、卡片盖到对话上；
  标题栏放不下的按钮收进 ⋮。窗口最小可以缩到 640 × 480。
- **搜索聊天记录。** 侧栏「搜索」新增「对话」页，可以搜全部或当前仓库的对话，选中后跳到那条消息；
  对话里有查找条，可在命中之间跳转。
- **Claude 插件与 MCP。** 设置的「插件」页可以安装、开关、更新、卸载 Claude 插件和 MCP 服务，
  Claude 对话可以用这些服务；「扩展」页改名「技能」。
- **对话显示更清楚。** 一段工作里的读文件、搜索、改文件各合成一行，命令每条一行并附结果；
  回合底部显示用时，思考可以展开看。
- **查看改动更方便。** 改动对比可以切换上下 / 并排；修改文件的审批卡直接显示带行号的改动；
  可以「复制补丁」；工具输出可以复制全部、查看全部。
- **输入框更省心。** 打错的 /命令 先提示、不直接发出；@ 引用的文件不存在会标出来；
  可以把文件拖进输入框作为附件。
- **换目录与子代理。** DeepSeek 对话里模型可以换工作目录，输入框下显示当前目录；换到工作区外会先问你，
  卡片上写明会读入那里的 AGENTS.md、CLAUDE.md 和技能。子代理都在后台运行，右栏「子代理」卡片显示
  每个子代理在做什么，可以查看对话或打断。
- **引擎升级。** DeepSeek 引擎（DSH）升到 0.2.1-rc.5，Claude Agent SDK 升到 0.3.316。

## 问题修复

- **不再往 Cadence / Allegro 的配置目录里写文件。** 装了 Cadence 的 Windows 电脑会设置
  环境变量 HOME（例如 `D:\cadence\Cadence\SPB_Data`），之前的版本因此每次启动都在那里生成
  `.pilab` 文件夹，影响 Allegro 导出 DXF。现在数据一律放在 `C:\Users\<用户名>\.pilab`；
  已经生成在 HOME 里的数据会在第一次启动时自动搬过来，聊天记录和登录都保留，原目录随后删除。
- 自动审核被服务商拒绝时，改为弹出确认卡片并显示服务商原话，不再当作出错。
- 引擎中断时提示「这一轮没有完成」并显示重新连接的进度，不再标红失败；中途停止的回合，用量不再显示成 0；
  思考强度按各模型的配置发送。
- 输入框里的 @ 引用、附件和发送失败的消息不再丢失，也不再串到别的对话。
- Claude 对话的「改动」面板显示 Edit / Write 的完整前后对比；重新打开的对话正确显示被停止的回合和回合用时。
- 文件在外部被改过时，编辑器保存会提示冲突，不再直接覆盖。
- 往上翻看历史时不再被拉回底部；切回对话时回到原来的阅读位置。
- 带「..」并经过目录联接的路径，权限判断不再可能把工作区外的位置当成工作区内。
- 长回复里的代码块显示更流畅，写完时不再变回纯文本。
