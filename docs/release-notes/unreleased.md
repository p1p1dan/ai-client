# PiLab Ai 1.2.1

## 新功能

- **界面换新。** 整体换成暖灰配色、更紧凑的字号；去掉左侧图标栏，侧栏可收起；
  标题栏贴到窗口最顶，窗口按钮在对话标题行右端。
- **右侧卡片窗。** 改动、文件、编辑器、Git、终端、运行、上下文、后台任务各是一张卡片，
  按需打开；拖动卡片标题可互换位置。改动卡片可在「本次对话」与「工作区」之间切换。
- **会话侧栏。** 对话右侧显示环境、上下文、改动、待办和运行中的任务；
  后台命令起了本机服务时，点一下即可在浏览器打开。
- **旁问。** 按 Ctrl+; 或输入 /btw，在小窗里就当前对话提问，不写回主对话，关掉即丢。
- **侧栏分组可切换。** 按仓库（默认）、按自己建的分组、按状态或按时间排列对话。
- **使用细节。** 用户消息悬停可复制、编辑重发、从这里分叉；改动显示行号并折叠未改部分；长提示词自动折叠；
  思考内容可复制；已发图片可预览；草稿重启后保留；输入法输入更稳。

- 关掉编辑器后，改动对比不再残留在界面上点不动。
