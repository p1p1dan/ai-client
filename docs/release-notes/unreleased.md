# PiLab Ai 1.1.0

## 新功能

- **首页。** 启动后与没有打开对话时显示首页：标题、最近 5 条对话，以及与对话页同样的输入框。
  在首页选好仓库与分支后直接发送即可开始对话，分支在发送时才切换。
- **计划模式。** 规划完成后弹出审阅卡，可以直接按计划执行，也可以继续讨论修改。
- **上下文压缩。** 手动 `/compact` 在时间线上显示进度，可附加说明，按 `Esc` 或停止键可取消；
  自动压缩同样在时间线上显示。「设置 · 模型」新增「自动压缩」一节，可查看每个模型约在多少
  token 时触发。
- **运行面板「逐步缓存」。** 显示本回合每一步的提示词与缓存读写量，缓存被重建时标出原因，
  并可复制诊断信息。
- **AI 服务。** 支持手工添加模型、按名称搜索模型，保留网关提供的显示名称；自定义服务的模型
  可单独配置推理强度与思考方式；模型请求的 User-Agent 可设置。
- **插件。** 设置里新增「插件」页，可开关经审核的插件（试点：Office 工具，默认关闭）。
- **右侧终端。** 右列可打开普通 shell 终端，与文件编辑器共用右列。
- **侧栏改版。** 参考 Claude 桌面版重新设计：去掉板块标题，临时对话放在列表最底，
  分组名改为小号灰色标签；仓库可按添加时间排列，也可切换为「按分组」归档，
  在会话右键菜单里「移到分组」。
- **权限菜单。** 改为单列五档，新增「设定目标…」。
- **欢迎页。** 加入 JYW 水印；「使用本机已有配置」入口暂不开放，已从欢迎页移除。

## 问题修复

- 检查更新遇到代理错误时改为直连重试一次。
- 模型目录每小时自动同步；同步失败时在模型菜单、设置与模型按钮上提示，不再静默。
- 加密机上切分支、查看变更与提交历史读不到 git 输出时自动改用备用方式读取，读取失败时界面
  显示错误，不再显示为「没有内容」。
- Windows 上可读取并编辑加密文件。
- 主题设为「跟随系统」后重启不再被改回浅色。
- 点开历史对话时显示「加载中」，不再误显示「还没有消息」。
- `E:\` 与 `E:/` 这类写法不同的同一目录不再被判为两个工作区。
- Ctrl+Enter 插话在送达前可以撤回，文字与附件放回输入框。
- 公司网关返回「该分组没有这个模型」时不再自动重试。
