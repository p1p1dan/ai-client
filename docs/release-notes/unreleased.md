# PiLab Ai 1.0.1

PiLab Ai 的第一个正式发布版本。自 v0.3.4 起的三个多月里，应用完成了一次更名和一次后端换代，
本版本是这两件事合流后的正式版：安装包、数据目录、运行时后端都已是新形态。

## 更名与数据迁移

- 应用更名为 **PiLab Ai**，安装包改为 `pilab-alpha-v<版本>-Setup.exe`，打包版数据目录固定为
  `<appData>/PiLabAi`（不再跟随 `productName`，避免路径中出现空格）。
- 首次启动自动迁移旧版本的数据：登录态、会话历史、仓库列表与对话列表都会从旧目录复制过来。
  **只复制不删除**，旧版本仍可回退使用。
- 迁移会依次识别此前各版本写过的目录名，包括更名前由 `package.json` 的 `name` 决定的
  `jyw-ai-client`。这是 1.0.0-test.17 及更早版本的实际情况，早期测试包曾因按 `productName`
  查找而迁移失败、升级后显示为全新安装。
- 升级后侧栏为空的问题已修复：仓库列表（`Local Storage`）与对话列表（`session-index.json`）
  此前未纳入迁移范围，现已一并补迁。旧数据与当前数据同时存在时按条目合并去重，不会覆盖新数据。
- 界面主题、布局等浏览器本地存储不在迁移范围内，升级后回到默认值。

## Runtime 换代

- **自有 Pi runtime 成为唯一后端。** 原 `AICLIENT_RUNTIME_BACKEND` 环境变量与旧引擎已移除，
  设置该变量不再有任何效果。需要回退时只能装回上一个安装包。
- 内嵌 Pi 终端、插件管理与模型配置不受影响：它们使用的是随包的 `pi` 可执行文件。
- Windows 安装版 worker 使用随包 Node，bash 使用实际安装的 Git for Windows；其余平台使用
  Electron utilityProcess。
- Windows 上 Node worker 的退出改为关闭 IPC 后自然退出，避免强制退出时的 libuv 断言。

## 子代理与能力

- 子代理（Task 系工具）落地：定义与模型目录、权限档与工具能力、独立会话归属与结算、重试、
  后台编排与自动交回，界面在设置中可管理。
- MCP 支持：声明的 stdio 服务器成为模型可调用的工具。
- 技能、提示词模板与斜杠命令可用；项目指令分级加载，并提供 local 层开关。
- 模型配置增强：模型目录覆盖 10 种 API 风格，`baseUrl` 按 wire 协议推导；用户自加的模型支持
  per-model 元信息编辑；凭据存入 vault。
- 权限体系：新增 `bypass` 完全放行档位；授权可按目录与命令前缀记忆并随会话持久化；
  回合进行中可热切换权限档位，排队中的请求按新档重判；授权闸串行化，排队中的请求不发卡也不计时。
- 对话能力：模型可向用户提问，问答卡一次一问；思考过程在流式期间即可见；工具调用在参数流式期
  就出现在时间线上；上下文用量可点击展开；审阅栏记录当前对话的 Edit/Write 改动。

## 体验与修复

- Chat 时间线改为工作组折叠：整轮的过程（思考、工具调用、授权活动）收进一个折叠头，最终回复
  留在折叠块之外；运行中默认展开，回合结束后自动折叠；两侧以旁白分隔，避免调用过程穿插在正文中。
- 回复正文按最终回复与中间说明区分色调；回合状态行显示时长、token 与思考量。
- 输入框聚焦时按 `Esc` 可停止当前回合；回合被停止后清除静默计时，「工作中」计时不再永久卡死。
- 主会话恢复 500 轮上限，触顶时先收尾再暂停，并给出继续入口；不再对单轮工具调用数量设限。
- 查看历史会话改为主进程只读回放，发送时才启动 worker，降低打开旧会话的开销。
- Git 面板的提交历史与分支列表在外部操作后自动刷新；文件面板增删改后立即重读。
- 修复权限审计事件缺失、用户消息气泡重复、附件丢失，以及内部权限记录出现在时间线的问题。

## 安装与回退

安装与后端说明见 [迁移说明](../pi-only-migration.md)，
退回上一个可用版本见 [回退说明](../pi-only-rollout-rollback.md)。

会话文件不因回退而不可读；但本版本新写入的行使用 v4 形状，旧版本能读到消息，读不到 v4 独有的
分支与压缩细节。回退请使用升级前的备份或独立的新会话验证，不要在唯一的原件上直接尝试。
