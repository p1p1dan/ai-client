# PiLab Ai 1.2.0

## 新功能

- **Claude 模型改由官方 Agent SDK 驱动。** Claude 对话的工具调用、计划模式、权限、子代理与后台
  任务都与 Claude Code 的行为一致，在加密等环境下调用工具更稳定。已有对话保持原来的引擎。
- **其余模型的工具补齐。** 新增网页抓取，文件内容搜索更强。
- **运行中的操作。** 回合进行中按回车即插话；停止只停主对话，子代理与后台任务继续运行；
  新增「转到后台」。
- **停止或失败的回合写明原因。** 输出保持展开，末尾写明原因和上游错误原文。
- **全自动档少打扰。** 只在删除等危险命令、以及操作工作区外的文件时询问。

## 问题修复

- 更新时不再下载两次。
- Claude 对话闲置一段时间后再发送，之前回合的最终输出不再消失、只剩「已工作」。
- 另一个对话正在重试上游时，新对话的消息不再卡在排队。
- Claude 对话在 Windows 上停止回合不再卡住。
